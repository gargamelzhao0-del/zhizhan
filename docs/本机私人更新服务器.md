# 本机私人更新服务器 · 1.9.0

## 手机安装即可连接

手机只安装知栈。服务器地址与只读访问凭证在本次 Android 发布构建中写入原生层，用户无需安装 Tailscale、登录账号或填写地址。电脑端使用已登录的 Tailscale Funnel 提供公网 HTTPS 入口。它不是仅限 tailnet 的 Serve；网络入口公开可达，版本清单与 APK 由应用凭证限制访问。

```text
知栈 Android（Wi-Fi / 移动网络）
  → HTTPS + 原生请求的 Bearer 凭证
  → 本机 Tailscale Funnel :8443
  → 127.0.0.1:8463 只读更新服务
  → 版本清单 + 已验证的签名 APK
```

入口：`https://win-bcgslpa5ria.taile4a98d.ts.net:8443/latest.json`。浏览器直接打开返回 401 是预期，因为浏览器没有应用凭证。不要把凭证放进 URL、截图或对话；它只保存在本机 `.private/update-service.json` 和私人 APK 中。APK 中的凭证可被逆向提取，不能把它宣称为不可复制的设备身份。本服务没有文章、笔记、附件或写入接口，不同步个人知识库。

2026-10-08 电脑登录完成。专用 8443 入口启用，原有 443 服务保留。启用后曾遇到 DNS NXDOMAIN；刷新本入口并等待解析传播后，普通公网域名请求已到达服务并返回预期 401。当前版本的完整认证下载、大小和摘要证据见 `remote-service-validation.json`；电脑公网验证不等于三星 S24 移动网络实测。

## 启动、停止与登录启动

在 TechVault 根目录运行：

```powershell
./scripts/start-private-updates.ps1 -EnableInternet
./scripts/register-update-startup.ps1
```

启动脚本核对版本目录、凭证、端口归属和 Tailscale 设备名。后台仅监听 127.0.0.1。当前用户启动目录中的 `ZhizhanPrivateUpdates.lnk` 在 Windows 账号登录后启动服务，不保存账户密码，不要求手机操作。Tailscale 需保持已登录与无人值守运行。

电脑仍需开机、联网且未休眠。未登录 Windows 时，本次登录启动项尚未启动；不承诺关机或休眠仍能更新。脚本不改路由器、防火墙或电脑睡眠设置。后台退出或发布新版本后可以重新执行启动脚本。

```powershell
./scripts/stop-private-updates.ps1
# 取消以后登录时自启，不停止当前服务：
./scripts/register-update-startup.ps1 -Remove
```

停止脚本核对进程路径与入口，防止误停其他进程。停用远程入口前确认 8443 仍属于知栈，再执行 `tailscale funnel --https=8443 off`；不要重置所有 Serve/Funnel 配置。

## 发布下一版

1. 保留 `.private/update-service.json` 和原签名密钥，固定域名与只读凭证不要每次重建。
2. 递增版本与 versionCode，完成检查并构建 APK，再运行 `node scripts/package-update.mjs`。
3. 运行停止脚本，随后运行 `start-private-updates.ps1 -EnableInternet`。服务启动时验证 APK 后加载不可变快照，不能靠替换正在服务的磁盘文件完成发布。
4. 运行 `node scripts/verify-update-service.mjs` 和 `node scripts/verify-update-service.mjs --remote`，验证匿名拒绝、认证清单、完整 APK 大小及 SHA-256。

目前只服务一个版本，切换后旧下载链接可能失效，手机重新检查即可取得最新清单。没有断点续传或零停机承诺。密钥或域名迁移必须同时考虑已安装手机；仅修改服务端会使旧安装包失去连接。真正需要轮换时先设计兼容迁移。

## 手机验收

已安装 1.3.0 的手机先手动覆盖安装 1.9.0，不要卸载或清除数据。已有内置更新服务的版本可以直接检查更新。后续打开“设置与资料 → 软件更新”，应显示更新服务已内置；相同版本应提示当前已是此发布地址提供的最新版本。

分别在同一 Wi-Fi、关闭 Wi-Fi 使用移动网络时点击检查更新。未来发布更高版本时验证下载、系统来源许可、安装与个人笔记保留。没有连接手机，本次尚未代替用户完成这些设备步骤。

资料离线功能不依赖服务在线。服务不可达会显示连接错误，允许手动重试；自动失败后五分钟才允许下一次前台/联网触发重试，避免持续请求。

协议依据：[Tailscale Funnel 官方说明](https://tailscale.com/docs/features/tailscale-funnel)。后台日志在 `.private/server/`，源码交付包不包含该目录。
