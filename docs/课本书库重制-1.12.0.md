## 阅读与交互

书库支持领域筛选、书名/册号查询及“只看有正文”。每册有独立封面、先修链接、导读、实际章节目录和课程规划；章节继续沿用笔记、收藏、历史、进度、检索、术语解释及备份机制。

正文转换为可编辑的 Markdown，图解使用受控的 SVG 扩展代码块。宽图、代码与表格在自己的容器内滚动。SVG 在渲染前清理脚本、外部资源、事件处理器等，局部 ID 加前缀，跨章节箭头定义移入当前图。HTML 实体通过清理后的 DOM 处理，避免 `&nbsp;` 在 XML 重解析时导致整图消失。

B23 的 PI 温控模型移植为离线交互组件：可改 Kp、Ki、对象时间常数、抗饱和开关，切换正常升温、环境降温、高设定回落与传感器故障。模型保留 0.1 s 采样、执行器 0～1 限幅和故障锁存；它是理想对象实验，不代表实物温控效果。没有加入代码编译或远程执行功能。

## 内容校读与验证边界

迁移中修正了已识别的错误：`0x200` 堆大小应为 512 字节；`f3ef 8305` 是两个半字；无 BL 指令只能说明这里未生成独立调用，不能据此否认 C 层内联函数；初始 MSP 在向量表偏移 `0x00`，复位入口在 `0x04`。相关依据为 [CMSIS 启动文件](https://arm-software.github.io/CMSIS_5/Core/html/startup_c_pg.html) 与 [CMSIS 核心寄存器访问](https://arm-software.github.io/CMSIS_6/main/Core/group__Core__Register__gr.html)。

本文不把“迁移无丢失”当成“所有技术事实已逐句审定”，也不把原型中的主机测试记录当成本轮重新执行的结果。板级例程还需要匹配器件、板卡、工具链和接线。B23 C 实验本轮用 `gcc -std=c11 -O2 -Wall -Wextra -Werror` 编译并执行通过，覆盖队列边界/回绕、Q15、故障锁存、限幅与 PI 收敛；Python 故障场景已运行并生成 CSV。其他实验源码已整理打包，没有声称逐一重新执行。

## 后续维护与使用

1. 修改原型后显式执行 `node scripts/import-textbooks.mjs <原型目录>`，核对导入报告与正文质量。生成的章节目录保留稳定 ID，后续插入或重排不应把旧笔记移到其他章节。
2. 日常构建使用保存在 `content/textbooks` 的快照，不依赖外部原型目录。执行 `npm run seed`，再执行 `node scripts/verify-textbooks.mjs`、`node scripts/verify-content.mjs` 和相关测试。
3. 需要独立修订文章时编辑快照，并同步维护对应审计记录；再次从原型导入会重建快照，应先回写或保留修订，避免丢失编辑成果。
4. 手机覆盖安装 1.12.0 后，在设置中点击“更新内置资料”。旧笔记与进度保留，修改过的文章沿用原文保护及新版副本规则，回收站内容不自动恢复。
