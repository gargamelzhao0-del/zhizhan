# 知栈 1.9.0 更新与发布

## 使用方式

Android 发布版已内置真实 HTTPS 服务地址与访问凭证。手机无需配置网络插件或地址。已安装 1.3.0 的用户需手动覆盖安装本版一次；保持原签名和应用身份，不要先卸载。

自动检查默认开启，在启动、回到前台、网络恢复时按间隔检查：上一次正常检查后 24 小时，失败后 5 分钟。它不是关闭应用后运行的定时后台任务。可关闭自动检查，或随时点击“检查更新”。发现版本只提醒，不自动下载或安装，编辑页隐藏更新提示以免打断输入。

点击“下载更新”后按进度下载，可取消。校验通过后点击“安装更新”，根据 Android 系统提示允许来源并确认安装。首次许可返回后需要再次点击继续安装。打开安装页面不等于安装成功，重新打开应用核对版本和个人资料。

Windows 浏览器版保留自定义 HTTPS 地址检查能力，但不包含私人服务凭证，不能直接读取这次受保护的入口。Windows 端使用新的 Windows 包更换程序，沿用同一浏览器及 `127.0.0.1:8462`。

## 安全边界与协议

原生请求仅接受 HTTPS，校验平台证书；只有固定的 scheme、host、有效端口完全相同的来源才附带 Bearer 凭证，携带凭证的请求跨来源重定向会被拒绝。最多跟随三次 HTTPS 重定向。请求使用 identity 编码，清单不超过 64 KiB，APK 不超过 128 MiB。

清单为 `format=zhizhan-update`、`schemaVersion=1`，包含 appId、version、整数 versionCode、minSdk、publishedAt、纯文本 notes 与 apk.url/bytes/sha256。APK URL 可以是同源相对路径。使用 versionCode 比较新旧。实际文件由脚本生成，不手动伪造大小或摘要，也不能只把清单版本提高而复用旧 APK。

下载逐块计算 SHA-256、限制大小，之后通过 PackageManager 检查包名、版本与签名。安装时再次验证缓存。沿用证书，当前没有签名轮换。服务端只接受只读请求并限制文件白名单，匿名请求返回 401。私人 APK 内的凭证不是防逆向方案，因此更新服务不承担个人资料存储。

## 构建与发布

```powershell
# 更新 package.json/lock、版本 code、课程版本及 release-notes 后：
node scripts/import-handbook.mjs
node scripts/verify-content.mjs
npm.cmd test
npm.cmd run test:e2e
./scripts/build-android.ps1 -Offline
node scripts/package-update.mjs
./scripts/stop-private-updates.ps1
./scripts/start-private-updates.ps1 -EnableInternet
node scripts/verify-update-service.mjs
node scripts/verify-update-service.mjs --remote
```

正式 APK 构建要求 `.private/update-service.json` 已存在。新部署可使用 `prepare-update-service.mjs` 生成真实地址对应的凭证；同地址重复执行保留凭证，不能在已交付后随意重建。`-AllowUnconfiguredUpdates` 只适用于明确标注的开发构建，不作为正常发布流程。

Android JVM 策略验证命令为 `./gradlew.bat :app:testReleaseUnitTest --offline`，随后生成 native-update-tests.json。最终 `package-release.py` 检查测试报告、源文件摘要、课程及 APK Web 资产一致性，再生成发布包与摘要。更新目录内 APK 也含只读访问凭证，按私人软件保存，不上传公开下载站。

## 数据与限制

软件更新不提交文章、笔记和附件。服务及转发设施会自然接触请求来源、时间及路径。应用保持 appId、签名、HTTPS origin 与数据库名。程序更新后，从“更新内置资料”载入本版课程：未修改的内置文更新，个人改文保留并另存内置新版，笔记/收藏/已读状态保留，回收站不复活。

下载不是系统后台持久任务，不支持断点续传。杀进程或清除缓存后重新检查下载。电脑必须在线、未睡眠；安装 APK 仍需要用户的系统确认。真机原生文件选择、来源许可、覆盖安装与 S24 移动网络连接待手机验收，不能由浏览器桥接模拟或 JVM 测试代替。

服务器操作与实际域名见 [本机私人更新服务器](本机私人更新服务器.md)。
