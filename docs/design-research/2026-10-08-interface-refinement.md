# 1.10.0 全界面复核与设计依据

本轮目标是改进手机学习产品的层级与细节。沿用已经确认的导航规则：普通页面双向滚动收起，到顶或点击展开；课程正文侧边玻璃球，点击展开居中紧凑导航。课程正文、数据库及更新入口不变。

## 参考与取舍

- [Apple Books 官方产品页](https://www.apple.com/apple-books/)：以封面辨认书目、继续阅读和正文为主要入口。应用在本产品中的是可辨认的原创课程封面和阅读优先级，没有复制官方图片、字体或图标。
- [Linear：A calmer interface for a product in motion](https://linear.app/now/behind-the-latest-design-refresh)：降低导航和装饰的视觉权重，统一操作位置，减少过度边框。本轮据此弱化非关键图标底色、合并设置入口、缩小资料卡片，并统一次要文字。
- Apple [Typography](https://developer.apple.com/design/human-interface-guidelines/typography) 与 [Layout](https://developer.apple.com/design/human-interface-guidelines/layout) 是进一步查阅入口；本次网页抓取仅返回需要 JavaScript，未将其当作已读取的具体规范证据。

调研用于设计决策，不代表知栈实现了苹果原生控件。玻璃只用于浮动导航；正文、表单和列表保持不透明，不增加全屏循环动画。

## 实际发现与处理

| 界面 | 发现 | 最终处理 |
| --- | --- | --- |
| 首页 | 强色主卡片与课程封面抢占注意力 | 改为轻色继续阅读卡，缩小书籍视觉，双列课程保持可见 |
| 资料库及分类 | 单个封面占一大段屏幕 | 横向封面列表，封面、标题、简介和进度共同排列 |
| 课程 | 阶段、正文入口和分隔线权重相近 | 阶段编号弱化，下一节有明确标记，章节加顺序编号 |
| 阅读与搜索 | 工具边框、标签与标题相互竞争 | 工具保持次要色，标签轻量化，正文标题与段落使用统一节奏 |
| 设置 | 收藏、回收站混入阅读偏好；窄屏入口换行生硬 | 常用入口集中为分组列表，阅读偏好独立；主题选择与字号预览统一 |
| 复习、收藏、回收站 | 空状态均用同一个图标 | 使用对应图标；有内容、无内容、未来复习均单独检查 |
| 编辑器 | 保存条拥挤、输入字段缺少常显标签 | 返回和保存分列，保存状态单独一行，知识库与标签加常显标签 |
| 编辑器玻璃 | 旧版静态导航失去定位边界，绝对定位玻璃层覆盖编辑页 | 导航改为相对定位并清除悬浮偏移；新增几何回归验证玻璃只在导航内部 |
| 弹窗与附件 | 标题、字段和底部操作节奏不一致 | 共用标题分隔、输入底色和圆角，继续保留滚动锁、焦点约束和原生返回 |

## 验证范围

scripts/audit-surfaces.mjs 用独立浏览器上下文检查主页面、课程、阅读、编辑、搜索、空状态、新建弹窗、历史、更新、备份以及带数据的笔记、复习、收藏和回收站。截图在 release/previews/1.10.0/surfaces。不访问用户已有浏览器数据库。

响应式审查继续覆盖窄屏、大字号、浅深色、横屏和桌面；既有导航、数据保存、导入更新和阅读回归继续运行。发布前通过数量与安装包摘要以当前验收记录为准。

截图可以发现布局和层级问题，不能证明审美偏好已被用户认可，也不能证明三星 S24 实际 GPU 帧率、系统字体缩放或输入法行为。本轮没有连接手机。
