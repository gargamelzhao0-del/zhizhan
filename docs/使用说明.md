# 知栈安装与使用

知栈保存你的开发项目、问题处理经验和技术课程。首版支持 Android 手机与 Windows 本地浏览器，两个设备的数据独立保存，不会自动同步。

## 在 Android 手机上安装

1. 将 `zhizhan-1.15.1-android.apk` 复制到手机。
2. 在手机文件管理器中打开 APK。按照系统提示，仅为本次打开 APK 的应用允许安装来源。
3. 安装后打开“知栈”。首次运行会把 27 册课程、个人项目手册、经验和引用附件保存到应用本地数据库，等待初始化结束。
4. 之后可以关闭网络继续阅读、编辑和搜索。

首版设置最低 Android 8.0，要求 Android System WebView 或对应 Chrome 内核至少为 109。尚未针对你的手机型号完成实机验收。若无法打开，先记录 Android 版本、WebView 版本和错误提示。

APK 声明联网与请求安装应用权限，用于 HTTPS 更新检查、下载和用户确认安装；没有录音、位置或共享存储读写权限。未配置发布地址时不发起更新请求，个人资料不上传。导入和导出通过系统文件选择器，只访问你选中的文件或保存位置。点击课程中的外部文档链接，需要外部浏览器和网络。

后续更新应直接覆盖安装使用同一签名的 APK。不要为了更新而先卸载；卸载会清除应用内部数据。

## 在 Windows 上使用

打开 `release/zhizhan-windows/`，保留内部目录结构，双击 `启动知栈.vbs`。若系统禁用脚本宿主，可运行 `启动知栈.cmd`；此方式需要保持命令窗口运行。

电脑端带有 Node.js 运行时，不需要另行安装开发环境。启动器只在 `127.0.0.1:8462` 提供本机页面。请使用日常使用的浏览器普通窗口，不使用无痕模式。再次启动会打开同一地址。更新电脑版前先关闭旧版服务；若旧版由隐藏启动器运行且不清楚对应进程，可重启电脑后再启动新版本。继续使用原浏览器与地址即可读取原有资料。

数据保存在该浏览器用户配置的站点数据库中，不在解压出来的程序目录中。换浏览器、清除站点数据、更换系统用户或修改地址会造成“看不到原资料”的情况。更换电脑前先导出备份。

手机与电脑各自第一次打开时都有相同的初始课程；之后一端的编辑不会影响另一端。

## 软件更新

Android 1.4.0 及以上已内置更新服务。手机无需安装 Tailscale 或填写地址。电脑在线时，启动、回到前台或恢复网络可自动检查：正常检查间隔 24 小时，失败重试间隔 5 分钟；也可随时点击“检查更新”。安装新版仍须按 Android 系统提示确认。已有 1.3.0 请手动覆盖安装本版一次，不要卸载；服务说明见 [本机私人更新服务器](本机私人更新服务器.md)。

发现新版后，在 Android 端点击下载，支持取消重试。校验通过后手动点击安装，由系统确认；若要求允许知栈安装来源，按系统提示操作，返回点击“继续安装”。取消安装不会清空已有资料。进程结束后需要重新下载；本版不提供断点续传或静默安装。

电脑端只查看 Android 版本信息，Windows 更新仍需替换程序包。发布文件与配置步骤见 [更新功能与发布指南](更新功能与发布指南.md)。资料包导入不迁移自定义更新地址；本版 Android 的内置更新入口无需配置。

## 修复旧版附件校验失败

1.5.0 修复了 Android 将无扩展名附件地址当成网页返回的问题。已有 1.4.0 可在设置中检查软件更新，或手动覆盖安装 1.5.0；已有 1.3.0 且未配置更新地址，可直接覆盖安装 APK。不要卸载或清除数据。完成软件升级后，再点击“更新内置资料”。

## 手机导航

底部四个入口：“学习”继续上次阅读并进入课程；“资料库”按项目、课程、经验查找所有知识库，也可进入收藏、新建知识库；“复习”查看到期内容；“我的”进入设置、软件更新、备份与导入。已有直达链接仍可打开原课程或项目。

手机右上角放大镜打开全库搜索，取消后回到当前页面。“学习”页右侧加号记录新知识。课程页底部“添加课程内容”可补写文章，项目和经验仍有“添加内容”。

## 手机阅读与课程浏览

1.15.0 将修订后的 27 册书库写入课程：317 个学习模块，共 407 个阅读章节（含路线、速查与附录）。课程首页从“从项目路线开始”进入八站学习安排，也可选择单册，先看“导读与实验资料”，按目标取舍。各册实验包和六项综合项目资料可离线查看、导出。

答案、拓展内容和验收面板默认折叠，按需展开。每个模块的“本章验收自评”记录解释、实现与迁移情况，关闭或重启后仍保留，并随完整 ZIP 备份保存。阅读进度与实验自评分别记录；目标板测量仍按各章条件验收。

旧 C++、Linux 与旧版课本继续保留在回收站，附着笔记与阅读状态保留。新课程使用独立标识，不会替换旧教程中的个人记录。

阅读工具栏 Aa 可直接调整字号，设置与阅读页保持同步。“我的 → 正文字号”可选择 16/18/20/22 px，并即时查看预览。手机弹窗靠近底部显示，内容超出可滚动；代码和表格在自身区域横向滚动，不挤出页面。

## 更新内置课程

安装 1.15.1 后首次打开会自动更新随包提供的课程，无需联网。此版本补齐导言、参考来源、路线图和 Linux 系统实验资料；已有个人文章与学习状态保留。正文上方可“展开全部”查看补充讲解、答案和自评，长代码与表格直接显示完整高度。也可在“设置与资料 → 更新内置资料”手动重试。

未修改过的内置正文会更新，原文保留在历史版本中，笔记、收藏、复习与阅读进度保留。修改过的文章保持原样，新增带“内置新版”的文章；新版从未读开始，个人笔记仍在原文。新版章节之间的链接会相应调整。回收站文章不会重新恢复；重复点击不会重复添加同一版内容。更新前建议先导出完整备份。

课程按从零基础到独立嵌入式项目组织。各册注明前置、交付物、延后内容和验收判据；主机模型、SDK 构建与真实硬件测量分别标识。先完成一条项目路线，无需通读 27 册。

## 组织知识

“项目档案”适合按项目保存需求、设计、代码、测试和版本演进。“技术课程”按文章顺序组成章节。“问题与经验”使用现象、复现、排查、根因、修复与验证模板。

在资料库点击“新建知识库”，选择类型、名称和简介。进入知识库后点击“添加内容”。已有知识库可通过页面底部“编辑知识库信息”修改名称和简介。

首版新文章追加到知识库末尾；尚未提供拖动排序和多级文件夹。可以通过章节标题和不同知识库组织内容。

## 编辑与保存

编辑器支持 Markdown。可以直接输入标题、列表、表格和代码，也可以使用工具栏插入模板。添加图片或附件时，文件会复制到本地知识库中。PNG、JPEG、GIF、WebP 可以在正文显示；其他文件可通过附件链接查看或导出。

标签支持中英文逗号分隔，重复标签会合并。

停止输入约半秒后自动保存。看到“所有修改已保存”表示数据库写入成功，也可以按“保存”或 `Ctrl+S`。离开编辑器时会尝试保存，未保存正文草稿同时保留在本机，重新进入该文章编辑器时恢复。若显示“尚未保存”，不要清理数据；保留草稿并解决提示的问题。

同一篇文章在多个窗口编辑时，旧版本不能静默覆盖新版本。出现冲突后，用“另存草稿副本”保存自己的内容，再检查原文。笔记也会检测另一窗口的修改，包括重新打开时恢复的旧草稿。冲突后可选择“草稿另存为文章”；只有确定不要当前草稿时才选择“放弃草稿，读取已保存笔记”。

阅读页的“版本历史”保留最近 30 次正文编辑前的版本。恢复只替换标题、正文与标签，保留当前笔记和学习状态。它属于本地历史，并不能替代独立文件备份。

## 阅读、查找与复习

搜索覆盖标题、正文、标签与学习笔记，支持中文与代码关键词。多个词以空格分开时，要求全部匹配。结果最多显示前 150 项，可继续增加关键词缩小范围。

Markdown 本篇锚点和跨篇章节链接可以跳到对应标题，常见的中文标题和小写连字符标题可识别。

阅读页提供小节目录、源码附件、代码复制、收藏和学习笔记。滚动会记录已到达的阅读进度；首页“继续阅读”回到已记录进度附近（内容或字号变化会影响精确位置）；点击“标记已读完”才记为完成。课程卡片根据已读完成的文章统计进度。

“加入复习”将文章加入当前复习清单。“已掌握”推进到下一阶段，后续间隔为 3、7、14、30、60 天；“再学一次”将下次复习安排在 1 天后。首版仅在应用内显示到期清单，不发送系统推送。

页面切换、笔记展开和弹窗采用短时过渡；系统启用“减少动态效果”时会取消位移动画。弹窗关闭后恢复原控件焦点，编辑预览返回时恢复光标和滚动位置。连续快速切页不会排队等待动画。

设置页可切换浅色或深色、调整正文字号。手机顶部齿轮进入设置；收藏可以在阅读页切换，手机设置页也提供收藏和回收站入口。

## 导入其他资料

已有 Markdown 可从“设置与资料 → 导入文件”导入。支持一次选择多篇 `.md`，并同时选择其引用的图片或附件。首版按所选文件中唯一匹配的文件名重写本地链接；同名文件存在歧义或没有选中引用文件时，不会猜测对应关系。请检查导入后的文章和图片。

导入后进入独立的“导入资料”知识库，可以修改名称并继续编辑。PDF、日志、源代码等可以作为附件保存；首版不把 PDF 正文转换成文章，也不索引附件全文。

知栈生成的完整 ZIP 使用“导入资料包”。应用先校验格式、长度、CRC 和附件 SHA-256，再展示文章及附件数量，点击确认后在一个事务中写入。相同且引用无需改变的文章跳过；同 ID 不同内容保留为导入副本，其引用目录与相关章节也可能生成副本，以保持链接指向正确；不会用备份静默覆盖现有版本。需要替换某篇内容时，先检查副本，再把旧内容移入回收站。

## 完整备份与恢复

点击“设置与资料 → 导出备份”。Android 中选择系统保存位置；Windows 中确认浏览器下载完成。建议把备份另存到电脑、移动存储或自己已有的备份位置。

ZIP 包含文章、附件、笔记、进度、课程验收自评、收藏、复习安排、回收站文章和历史版本，也提供可独立阅读的 `markdown/` 与原始 `assets/` 文件。**正文导出为单篇 Markdown 不包含附件和应用状态，不能作为完整备份。**

导入完整 ZIP 可以在另一端继续阅读和整理，这是手动转移，不是同步或自动合并。备份没有加密，包含你的正文、代码和附件，请只存放到自己信任的位置。

建议每次整理一批重要内容后导出。上次导出时间表示应用发起了导出；电脑端仍需确认下载文件确实保存成功。

## 首版容量与边界

| 项目 | 限制 |
| --- | --- |
| 单个新附件 | 20 MiB |
| 单次 Markdown 导入 | 500 个文件、合计 64 MiB；单篇 Markdown 文件 2 MiB |
| 文章编辑正文 | 2 × 1024 × 1024 个字符 |
| 单篇笔记 | 128 × 1024 个字符 |
| 单包导入导出 | 压缩文件及解压内容合计分别不超过 128 MiB；单文件不超过 24 MiB |
| 资料包条目 | 1000 个知识库、10000 篇文章、5000 个附件、10000 个历史版本 |

大包压缩和校验可能需要等待，手机可用空间和内存也会限制实际容量。首版适合技术文章、代码和中小型附件，不适合大量视频、镜像或完整编译产物。

回收站支持恢复，首版没有永久清空入口。附件可能被多篇文章和历史版本引用，首版不自动回收，避免误删；空间规模显著增长时，应先导出完整备份再规划分库整理。

## 1.8.0 界面与动效

底部四个入口显示在浮动导航中，选中背景跟随当前页面移动。分类、课程视图及主题切换采用相同反馈。点击卡片、收藏、展开搜索与关闭弹窗都有短时反馈，不需要等待动画结束才能继续操作。手机旋转后导航会重新对齐。

动效遵循系统的“减少动态效果”偏好；开启后保留颜色与选中状态，取消移动和缩放。减少透明度或高对比度偏好会把导航换为实色。各 Android/WebView 版本对这些系统偏好的映射可能不同，需在手机上确认。课程展开在支持相关 CSS 的 WebView 中平滑变化，旧内核直接展开。

## 1.10.2 滚动与阅读导航

资料库和分类页以紧凑的横向封面列表呈现。课程目录标记下一节未读内容；“我的”顶部集中提供收藏、回收站、软件更新和备份入口。编辑页的知识库、标签、保存按钮和保存状态分别显示。

普通页面向上或向下滚动都会收起上下导航，只有回到页面最顶部或点击导航/搜索后展开。方向反转不会自动展开。

进入课程中的任一正文后，顶部保持小搜索按钮，下方导航变成右下侧的小玻璃球；即使回到本课顶部也保持收起。点玻璃球会展开底部居中的四图标紧凑导航。继续滚动、点击正文、按 Escape 或系统返回键会收回玻璃球；再次进入章节也默认显示玻璃球。点击四个入口仍可直接跳转对应页面。

需要搜索时点击搜索按钮，输入期间临时展开输入框；关闭后恢复该页面的导航状态。输入法缩小可用视口时隐藏底部浮层。球和导航按钮均保留至少 48×48 CSS px 的点击区域，玻璃球可见直径为 36px。减少动态效果、高对比度和减少透明度偏好继续适用。

系统返回键处理已通过同一前端事件验证；真实 Android 输入法、安全区域和手势仍需要手机确认。
