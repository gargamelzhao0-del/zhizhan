## 1.0.1 · 2026-10-07

本次以保护已有资料、补齐编辑和导入流程为主，没有增加同步、AI 或账号服务。

### 编辑与笔记

- 修复标签输入时逗号立即消失的问题，支持连续输入和去重。
- 笔记草稿保存修改前的文本基线，重开应用后也不能覆盖后来保存的新笔记。冲突草稿可以另存为文章。
- 修复滚动进度与完成标记竞争，以及重新学习后不继续记录进度的问题。
- 限制副本标题长度，避免最长标题加后缀后无法再次备份。

### 资料包与阅读

- 导入发生冲突时，相关章节和目录的链接会一起指向导入副本，支持循环引用。
- 使用 Markdown 语法树识别链接，不再替换正文或代码示例中的相似文本。保留 GFM 删除线、表格、引用式链接和标题锚点。
- 补齐本篇及跨篇标题跳转，支持含括号的附件文件名。
- 流程图、图片更换内容后清除旧显示状态。
- ZIP 压缩、解压及 CRC 校验移到独立 Worker，保留大小、数量、路径和附件摘要校验。仍需多型号手机内存压力验证。

### Android 与发布

- 系统返回优先处理弹窗、搜索和正在进行的导入导出；编辑页先保存再返回。
- 原生文件保存完成时先释放暂存状态，再通知页面成功，减少连续保存的状态竞争。
- 发布过程读取统一版本，核验 APK 资源及版本，源码包排除签名私钥和本机配置。
- APK 沿用原签名及应用标识，versionCode 从 1 增加至 2。更新时覆盖安装，不要先卸载。
