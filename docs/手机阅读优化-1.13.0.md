# 知栈 1.13.0 · 手机阅读优化

这次改版围绕三星 S24 等窄屏设备，把正文、辅助解释和宽内容分开呈现。正文仍完整、连续地保存在本机；图解、代码、表格通过独立查看面板展开。课程和项目实录使用同一阅读组件。

## 阅读方式

文章顶部保留返回、字号、收藏与更多操作。日期、标签、来源、编辑和历史移到“更多”面板，减少正文前的占用。长文章提供小节导航：左右按钮跳到相邻标题，中间打开目录；目录标出当前小节。这里采用连续正文加小节跳读，不强制拆页，便于前后对照。

手机目录、阅读设置与术语解释使用底部面板。图解默认适应正文宽度，全屏后可按按钮放大至 400%，滑动查看局部或恢复适合屏幕。代码预览限制高度，全屏保留全部文本与缩进，可切换自动换行和复制完整代码。表格保留表头与行列关系，在独立区域横向阅读。

正文默认 18 px、1.8 倍行距；可选 16、18、20、22、26、30、36 px 与紧凑、标准、宽松三档行距。面板使用实色阅读背景，160 ms 的位移与淡入；系统开启减少动态效果时关闭这段动画。全屏查看不依赖网络，也不执行代码。

## 位置与数据保护

阅读位置和最高完成进度分开保存：`reading-position:<文章 ID>` 记录可见正文块的索引、文本签名和块内比例。内容插入段落后，恢复逻辑尝试通过签名重新定位；匹配失败或旧版本没有位置记录时，回退到既有阅读进度。较长代码收起后，也不会把“最高进度”误当作最近停留的位置。

面板通过原生 `dialog` 限定焦点和背景交互。Android 返回事件先关闭阅读面板；关闭后恢复触发按钮焦点，不主动将页面滚回顶部。全屏查看时保留原预览的占位高度，避免正文上下跳动；同一幅 SVG 不同时复制为两套 DOM，防止内部箭头 ID 冲突。

沿用原有文章 ID、正文、附件、笔记冲突保护、收藏、历史及备份。内置资料保持 `2026.10.09.5`，安装此次应用更新即可使用新阅读界面，无须为此重复导入教材。Android 版本为 1.13.0，versionCode 19，沿用原签名。

## 验证范围

单元测试 85 项通过；界面与数据回归 47 项通过、1 项重复桌面检查跳过；后续阅读面板专项 8 项及编辑预览返回专项 2 项通过。

自动化覆盖桌面和 393 px 手机视口，以及 320 px、大字号、深色模式、短横屏弹窗、离线实验、术语面板、目录定位、段落续读、完整代码与表格、焦点返回和 Android 返回事件分发。构建产物另校验 APK 签名和更新包哈希。

浏览器视口测试不能替代 S24 实机 WebView、系统手势和字体缩放的最终体验验收。图解放大使用界面按钮及滚动查看，不声称提供图像编辑器级的双指缩放。

## 维护入口

- `src/App.tsx`：阅读工具、目录、小节导航、字号与行距、位置存取。
- `src/ReaderDialog.tsx`：底部面板与全屏容器、焦点及返回处理。
- `src/Editor.tsx`：全屏查看期间保留编辑状态，避免返回事件同时退出编辑。
- `src/ReaderMedia.tsx`：图解、表格、代码的预览与全屏展示。
- `src/readingPosition.ts`：段落位置采集与签名匹配。
- `src/reader.css`：阅读排版、手机面板、媒体布局及减少动态效果。
- `e2e/reader-experience.spec.ts`：阅读改版的专门回归用例。
