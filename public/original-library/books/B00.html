Module 01 · 起步

程序是怎么跑起来的

在写第一行代码前，先建立一张地图：你写的文本，怎么变成会运行的程序。 理解这条链路（写→编译→链接→运行），你就知道"报错时该看哪一环"。

1.2 第一个程序

约定：所有示例都在命令行用 gcc 编译。先看这个最小程序，逐行读注释：

hello.c — 最小可运行程序 C 
#include <stdio.h>          /* 引入 printf 的声明 */

int main(void)              /* 程序从 main 开始执行；void 表示"不接收参数" */
{
    printf("Hello, embedded!\n");   /* \n 表示换行 */
    return 0;               /* 返回 0 表示"正常结束" */
}

1.3 每一步在做什么

命令产物作用
gcc hello.c -o hellohello（可执行）编译 + 链接一步到位
gcc -c hello.c -o hello.ohello.o（目标文件）只编译，不链接

⚠ 新手最常见的三个报错
  • error: expected ';'：漏了分号——去报错指出的上一行找。
  • warning: implicit declaration of function 'printf'：忘了 #include <stdio.h>。
  • undefined reference to 'main'：没有 main，或没把它加进编译命令。

1.4 程序运行时的样子

程序运行起来后，代码在被"一条条执行"，用到的变量住在内存里。 这一册后面会不断回到"内存里到底发生了什么"——这也是第①册《嵌入式 C 精读》的主线。 现在你只要记住：变量 = 内存里的一块，有名字、有类型。

1.5 编译期报错 vs 链接期报错

报错先判断"在哪一环"，再对症下药。前者看源文件语法，后者看"谁没被提供"。

报错关键字发生阶段典型原因
expected ';'编译期漏分号——看上一行
undeclared编译期变量没声明 / 拼错名字
implicit declaration编译期忘了 #include
undefined reference链接期函数没实现 / 没加进编译
multiple definition链接期同名全局符号定义了两次

◆ 自测 · Module 01（先答再看）

  1. 填空：把 hello.c 变成可执行文件的两个阶段是 ______ 和 ______。

    编译与链接。编译把源文件变成目标文件（.o），链接把目标文件与库拼成可执行文件。

  2. 判断：gcc hello.c -o hello 这条命令里，hello.c 是输出的程序名。

    错。hello.c 是输入（源文件），-o hello 才指定输出名为 hello。

  3. 诊断：报错 undefined reference to 'main'，最可能的原因？

    本章的宿主环境程序缺少 main 函数，或它没有被编译进去。裸机等独立环境的启动入口由实现、启动文件和链接配置约定，不能把这里的规则直接套用到所有 C 程序。

  4. 动手：把 hello.c 的最后一行 return 0; 删掉再编译运行，看会发生什么；再删掉一个分号试试。

    删 return 0; 在 C99 及之后的宿主环境中仍是合法程序：走到 main 末尾等价于返回 0，不要求编译器告警；删分号会得到 expected ';'——亲手制造一次错误，比看文字记得牢。

  5. 判断：编译器报的错，位置一定就在那一行的语法上。

    不一定。C 的报错常指向"发现问题的位置"，而问题往往在上一行或更早（比如漏分号）。第一处报错最值得看。

答不上来的，翻回对应小节再看一遍——比直接背结论有效得多。

Module 02 · 数据

变量、类型与表达式

程序做的事就是"把数据存起来、算出来"。这一节讲清 C 的基本类型、变量怎么声明、printf 怎么输出， 以及一个新手最容易踩的坑：整数除法。

◷ 约 55 分钟◈ int/double/char · printf · 运算符⚑ 类型决定一切

2.1 四个最常用的类型

类型存什么本机大小输出格式
int整数（如 7, -3）4 字节%d
double小数（如 3.5）8 字节%.2f（保留 2 位）
char单个字符（如 'A'）1 字节%c

◆ "类型"到底决定了什么

① 能存什么（整数还是小数）；② 占多少字节（sizeof）；③ 能做哪些运算、结果是什么类型。三者都由类型决定。

2.2 声明变量、算一算、打印出来

types.c — 变量/类型/运算符（可运行） C 
#include <stdio.h>

int main(void)
{
    int    n = 7;              /* 整数 */
    double x = 3.5;            /* 小数（双精度） */
    char   c = 'A';            /* 单个字符 */
    int    y = n / 2;          /* 整数相除：结果取整 */
    double z = n / 2.0;        /* 有一个是小数 → 结果是小数 */

    printf("int    = %d,  sizeof = %zu 字节\n", n, sizeof(int));
    printf("double = %.2f, sizeof = %zu 字节\n", x, sizeof(double));
    printf("char   = %c,  sizeof = %zu 字节\n", c, sizeof(char));
    printf("7/2 = %d,  7/2.0 = %.1f\n", y, z);
    return 0;
}
bash — 复跑：bash tools/probes/m02.sh
命令与代码
$ gcc -std=c11 -Wall -Wextra types.c -o types && ./types
int    = 7,  sizeof = 4 字节
double = 3.50, sizeof = 8 字节
char   = A,  sizeof = 1 字节
7/2 = 3,  7/2.0 = 3.5

2.3 最容易踩的坑：整数除法

上面输出里 7/2 = 3 而不是 3.5——因为 两个 int 相除，结果还是 int，小数部分被丢掉。 想得到小数，必须让其中一个操作数变成小数（写成 7 / 2.0 或把整数转成 double）。

⚠ 运算符优先级与"意外结果"
  • a + b * c 先算乘除、后算加减；不确定就加括号。
  • = 是赋值，== 是判断相等——写 if (x = 0) 是常见错误（永远为"假"且改了 x）。
  • % 是取余（只对整数）；7 % 2 == 1。

2.4 从键盘读入：scanf

read_input.c — 用 scanf 读两个整数求和 C 
#include <stdio.h>

int main(void)
{
    int a, b;
    printf("输入两个整数（空格分隔）：");
    if (scanf("%d %d", &a, &b) != 2) {      /* 注意：scanf 需要"地址"(&) */
        printf("输入格式不对\n");
        return 1;
    }
    printf("%d + %d = %d\n", a, b, a + b);
    return 0;
}
⚠ scanf 必须传"地址"

写 scanf("%d", a) 是错的——要写 &a（& 取地址）。原因在 M06 讲指针时你会彻底明白：scanf 要往你的变量里写值，就得知道它在内存的地址。

4.3 作用域：变量在哪儿有效

Module 06 · 地址

指针入门

指针是 C 的"分水岭"，也是嵌入式绕不开的东西（寄存器、DMA、缓冲区都要它）。 别怕：指针就是一个保存"地址"的变量。& 取地址，* 按地址取内容。

◷ 约 60 分钟◈ &/* · 指针与数组 · 传址⚑ 嵌入式的核心

6.1 指针是什么：一张图

FIG 6.1 变量有名有地址；指针保存的就是"地址"
&x：取 x 的地址；*p：按 p 里的地址访问那块内存。p 是指针（存地址），*p 是它指向的值。

6.2 三个最实用的用法

pointer.c — 取地址/解引用/传址/数组遍历（可运行） C 
#include <stdio.h>

void swap(int *a, int *b) {                  /* 交换：通过指针改调用方的变量 */
    int t = *a; *a = *b; *b = t;
}

int main(void)
{
    int x = 3, y = 8;
    int *p = &x;                             /* p 保存 x 的地址 */
    printf("x=%d   *p=%d   (p 指向 x，所以 *p 就是 x)\n", x, *p);

    *p = 10;                                 /* 通过指针改 x */
    printf("after *p=10: x=%d\n", x);

    swap(&x, &y);                            /* 传"地址"进去，才能改出来 */
    printf("after swap:  x=%d  y=%d\n", x, y);

    int a[4] = {1, 2, 3, 4};
    int *q = a;                              /* 数组名就是首元素地址 */
    int s = 0;
    for (int i = 0; i < 4; i++) s += *(q + i);
    printf("array sum via pointer = %d\n", s);
    return 0;
}

        printf("%d\n", *p);             /* 只有非空才解引用，避免崩溃 */
    } else {

    }
    return 0;
}

结构体、枚举与 typedef

自带类型不够用时，就把数据打包成自己的类型。struct 表示"一条记录"，enum 表示"一组命名状态"， typedef 让类型名更短好写。

7.1 结构体：把相关数据打包

structs.c — 结构体/枚举/typedef（可运行） C 
#include <stdio.h>

typedef struct { int x, y; } Point;          /* typedef：给类型起短名 */
enum Color { RED, GREEN, BLUE };             /* 枚举：一组命名常量 */

double dist2(const Point *p) {               /* 传指针，省拷贝 */
    return (double)p->x * p->x + (double)p->y * p->y;
}

int main(void)
{
    Point pts[3] = { {0, 0}, {3, 4}, {1, 1} };
    for (int i = 0; i < 3; i++)
        printf("P%d=(%d,%d)  dist2=%.0f\n", i, pts[i].x, pts[i].y, dist2(&pts[i]));

    enum Color c = GREEN;
    printf("color index = %d\n", c);
    return 0;
}

#endif
math_utils.c — 定义（实现） C 
#include "math_utils.h"
int add(int a, int b) { return a + b; }
int max3(int a, int b, int c) {
    int m = a;
    if (b > m) m = b;
    if (c > m) m = c;
    return m;
}

◆ include guard 是什么

#ifndef MATH_UTILS_H / #define / #endif：防止同一个头文件被重复展开（比如 A 和 B 都包含了它）， 否则会出现"重复定义"。每个头文件都该有它。

每个 .c 先各自编译成 .o（目标文件），最后链接器把它们拼成 app。 main.o 里调用 add 时只是"占个位"，链接阶段才在 math_utils.o 里找到它。

app: main.o math_utils.o

main.o: main.c math_utils.h
	$(CC) $(CFLAGS) -c main.c -o main.o
math_utils.o: math_utils.c math_utils.h
	$(CC) $(CFLAGS) -c math_utils.c -o math_utils.o
clean:
	rm -f *.o app

9.1 题目：统计一组测量值

需求：给一组小数，算出最小值、最大值、平均值，并以一条记录（结构体）返回。这正是设备日志/传感器数据的常见处理。

stats.h — 接口：一个结构体 + 一个函数 C 
#ifndef STATS_H
#define STATS_H
typedef struct { double min, max, mean; int n; } Stats;
Stats stats_of(const double *xs, int n);
#endif
stats.c — 实现（数组 + 循环 + 指针参数） C 
#include "stats.h"
Stats stats_of(const double *xs, int n) {
    Stats s = {0, 0, 0, n};
    if (n <= 0) return s;
    s.min = s.max = xs[0];
    double sum = 0;
    for (int i = 0; i < n; i++) {
        if (xs[i] < s.min) s.min = xs[i];
        if (xs[i] > s.max) s.max = xs[i];
        sum += xs[i];
    }
    s.mean = sum / n;
    return s;
}
main.c — 驱动 C 
#include <stdio.h>
#include "stats.h"
int main(void) {
    double xs[] = {3.2, 1.5, 9.8, 4.0, 2.6, 7.1};
    int n = (int)(sizeof(xs) / sizeof(xs[0]));
    Stats s = stats_of(xs, n);
    printf("samples=%d  min=%.1f  max=%.1f  mean=%.2f\n", s.n, s.min, s.max, s.mean);
    return 0;
}

机制与契约

输入解析的关键是知道函数到底消费了什么。strtol 同时返回数值并通过 end 返回停止位置；只看返回的 0 无法区分合法零与解析失败。先清 errno，再检查没有消费字符、残留字符、ERANGE 和 int 的上下界。只有全部通过才更新输出。示例接受前导空白和符号，拒绝尾部空白与小数；这是接口政策，而不是所有解析器的统一要求。文件 IO 则要分别检查打开、读取和关闭结果，保留错误发生的位置。

*result = (int)v;

Module 11 · 实现与验收

动态内存与对象生命周期

管理动态数组的容量与所有权，分配失败后仍保留有效状态。

前置：本册前面的类型、函数与资源管理阅读约 15–25 分钟；实践约 30–60 分钟（规划估计）

机制与契约

size 是已初始化元素数，capacity 是可用存储槽数，data 是唯一拥有的分配块。扩容先检查容量乘法是否溢出，再把 realloc 返回值放入临时指针。成功后同时提交指针与容量；失败保留旧块、旧 size 和旧 capacity。扩容可能移动存储，所以旧元素指针不能继续使用。清理函数归还所有权并重置对象，避免再次释放旧地址。实验注入一次分配失败，以验证程序能继续扩容。

关键片段 · 完整可运行项目见下方源码
int *next = s->resize(s->data, bytes);
if (!next) return 0; /* 旧对象不变 */
s->data = next;
s->capacity = new_capacity;

边界与误用

直接 data=realloc(data,n) 会在失败时丢失旧指针；先窄类型相乘再转 size_t 无法修复溢出。示例分配器必须与 free 兼容。该主机实现不提供线程安全，也不承诺 MCU 的确定性分配耗时；硬实时路径优先考虑固定容量。
