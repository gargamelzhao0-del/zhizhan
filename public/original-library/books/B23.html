B23-M01从需求到算法、数据与控制链入门正文

学习范围 · 被控对象；数据与单位；误差；执行器；观测与闭环验证

先用一个可测量的目标组织学习：让温度保持在 45°C，受到散热变化后仍能恢复。温度是被控量 y，45°C 是设定值 r，加热占空比是控制量 u，误差 e=r−y。算法把传感器读数转成可信的 y，控制器根据误差计算 u，日志帮助你解释结果。

一个数字离开单位和时间，就容易被误用。记录“2048”无法判断它是 ADC 原始码、毫伏还是编码器计数。建议把原始值、校准值、采样时刻、序号、质量标志一起保存。离线 Python 可以验证算法，MCU 负责在规定周期内运行；两端要使用相同的参数版本和输入语义。

对象本册例子必须约定
r / y目标温度 / 测量温度°C；测量是否有效
u0～1 的加热占空比限幅、更新周期、故障时为 0
Ts0.1 秒由采样/调度保证；记录实际抖动
结果误差、饱和时长、故障响应仿真结果与板上实测分别记录

学习顺序是先建立可回放的数据链，再校准和滤波，然后辨识对象并闭环，最后处理资源预算与失败路径。本册提供 18 章实战入门；完整证明、复杂控制器设计和具体器件驱动，可继续结合关联分册学习。

B23-M02算法选型：复杂度、内存与最坏耗时入门正文

学习范围 · 复杂度；固定内存；最坏输入；WCET 测量；CPU 与总线预算

嵌入式算法不仅要算对，还必须按时算完。O(N) 描述输入增大时的趋势，不等于执行时间。乘法是否有硬件支持、缓存是否命中、DMA 是否争用总线、任务是否被抢占，都会改变实际延迟。先限制最大输入长度，再给 CPU、RAM 和延迟分配预算。

例如 100 Hz 的控制周期是 10 ms。假设采样处理 0.6 ms、控制 0.2 ms、输出 0.1 ms，单次计算总量为 0.9 ms；还需考虑中断、阻塞和调度造成的响应时间。一次平均 0.9 ms 的测量不能证明最坏情况下满足 10 ms。

任务常见方法工程取舍
滑动平均滚动和，单次 O(1)需要窗口存储，和可能溢出
小窗口中值固定数组排序窗口短时简单；延迟随窗口增大
查标定表二分 O(log N) 或等距索引 O(1)需定义边界、单调性和外插策略
频谱分析FFT，通常 O(N log N)需要工作区；块处理增加等待延迟

主机可用 time.perf_counter() 比较实现，但它不能代替 MCU 实测。板上用可用的周期计数器或 GPIO 翻转配合逻辑分析仪，记录输入上限、优化级别、时钟与中断负载。没有完整分析覆盖时，测得的最大值应称为“本次测量最大耗时”。

检查结果

输出长度—耗时—RAM 对照表；包含窗口未满、最大长度和高负载场景。

核对与延伸：Python：单调计时与性能计数器

B23-M03环形缓冲、滑动窗口与流式算法入门正文

学习范围 · head/tail；满空区分；溢出策略；滚动和；ISR 与任务交接

采样生产数据，处理任务消费数据，环形缓冲把两者解耦。采用“留一个空槽”的实现时，head==tail 表示空，下一写索引等于 tail 表示满。数组长度 8 只能暂存 7 个元素；容量估计必须使用可用槽数。

满时可以拒绝新数据、覆盖最旧数据，或触发降载，但策略必须明确。控制链中丢掉旧数据和丢掉新数据会产生不同的时延。记录丢样计数、队列最高水位和序号差，才能判断后端算得慢还是源头采样不连续。

C · 串行访问示意；完整 push/pop 与边界检查见 algorithms.c
命令与代码
unsigned next = (q->head + 1u) & (CAPACITY - 1u);
if (next == q->tail) return false; /* 满，拒绝写入 */
q->data[q->head] = value;
q->head = next;

位与回绕要求 CAPACITY 是 2 的幂。示例只演示串行访问；ISR 与任务共享时，还必须保证数据先写完、索引后发布，以及读取索引和数据之间的顺序。volatile 不能单独保证并发正确性。移植时选择芯片/RTOS 支持的临界区、原子操作或队列，并核对 DMA 缓存一致性。

长度 W 的滑动平均可用 sum←sum−旧值+新值，每次只做常数次运算；启动时用真实有效样本数做除数。整数累计和要按 W×输入最大值选择位宽，不能先在窄类型里相加后再转换。

检查结果

FIFO 顺序正确；满和空的行为可解释；移植方案明确谁修改哪个索引。

B23-M04排序、查找与标定表插值入门正文

学习范围 · 二分查找；有序表；线性插值；外插；查表误差

传感器常用分段标定表把原始读数 x 转成物理量 y。找到相邻点 (x0,y0)、(x1,y1)，计算 y=y0+(y1−y0)(x−x0)/(x1−x0)。输入表的 x 必须严格递增，重复节点会导致除零，乱序会导致区间定位错误。

例如 x=1.5 V 位于 1 V→20°C 与 2 V→50°C 之间，插值得到 35°C。这个结果只反映局部直线假设；测量误差、表点误差和曲线弯曲仍然存在。把检查点放在标定节点之间，才能评价插值误差。

Python · 区间公式
命令与代码
x0, y0 = 1.0, 20.0
x1, y1 = 2.0, 50.0
x = 1.5
assert x1 > x0
y = y0 + (y1 - y0) * (x - x0) / (x1 - x0)
assert y == 35.0

非等距节点可二分定位，等距表可直接算索引。区间外输入要明确选择报错、钳位或外插；温控传感器超出已验证范围时，继续外插可能把断线变成正常温度。NumPy 和 CMSIS-DSP 的接口边界行为需要分别核对，不能假设两个函数天然一致。

检查结果

非法表被拒绝；每个边界行为有明确结果；节点间测试给出最大物理量误差。

核对与延伸：ARM CMSIS-DSP：线性插值

B23-M05状态机：正常、降级与故障锁存入门正文

学习范围 · 状态；事件；转换条件；故障锁存；恢复与重新使能

控制公式解决“输出多少”，状态机解决“此刻是否允许输出”。为温控定义 SAFE、ACTIVE、FAULT：上电进入 SAFE；数据有效且用户使能后进入 ACTIVE；传感器失效或超温进入 FAULT，并立即关闭加热。故障恢复后，需要显式复位回到 SAFE，再经过使能才能重新运行。

把优先级写在转换逻辑里：故障条件先于使能条件。否则复位和超温同一周期出现时，程序可能短暂恢复输出。每个状态还应说明进入动作，例如清理积分、初始化滤波状态、记录故障码；这些动作和持续执行的状态动作要区分。

C · 逻辑顺序，完整函数见 algorithms.c
命令与代码
if (!sensor_ok || overtemp) return FAULT;
if (state == FAULT) return reset ? SAFE : FAULT;
if (state == SAFE && arm) return ACTIVE;
return state;

恢复不等于抹掉故障记录。保存首次故障时间和原因，复位只改变运行状态。计时器溢出、通讯重连、设备重启都属于输入事件；用状态—事件表逐项考虑，能减少多个布尔标志互相矛盾的情况。

动手练习

列出每个状态遇到 sensor_invalid、overtemp、reset、arm 时的结果，运行 C 实验中的锁存断言。

检查结果

故障优先；数据恢复不会自动重新输出；复位和使能不会在一次转换中越过 SAFE。

核对与延伸：W3C SCXML：状态与转换语义（本例为自写 C）

B23-M06数值计算、浮点误差与 Q15 定点入门正文

学习范围 · 量纲；溢出；Q15；宽乘法；饱和；量化误差

先估计数值范围，再决定存储格式。Q15 常把有符号 16 位整数解释为整数值/32768，范围为 −1 到 1−1/32768。把物理量映射进去之前，必须约定满量程。例如 ±100°C 对应这个范围时，每个量化步长约为 0.00305°C。

两个 Q15 相乘得到带 30 个小数位的中间积，应在 32 位类型中完成乘法，再缩回 Q15。−1×−1 数学上等于 1，但正端不能表示 1，须饱和到 32767。以下使用整数除法向零截断，避免把负数右移的实现细节当成统一规则。

C · 完整函数和端点断言见 algorithms.c
命令与代码
int32_t v = ((int32_t)x * (int32_t)y) / 32768;
if (v > 32767) v = 32767;
if (v < -32768) v = -32768;
return (int16_t)v;

浮点也需要范围检查。NaN 会使普通大小比较失去预期，不能只靠“低于阈值”判定传感器正常。校验 isfinite()、周期是否为正、单位转换是否一致。累计大量近似值时，参考计算可使用更高精度；误差比较采用明确的绝对/相对容差。

滤波和控制中的量化会改变闭环行为。先用高精度离线模型作为基线，再用目标格式回放同一份输入，比较最大误差、饱和次数和响应指标；不能仅凭几个正常输入宣布定点移植成功。

动手练习

检查 0、±0.5、−1×−1、接近正满量程及小负数相乘；比较浮点与定点误差。

检查结果

中间积不溢出；正端正确饱和；量化和截断规则写入参数说明。

核对与延伸：CMSIS-DSP：Q15乘法与饱和

B23-M07数据采集：时间戳、序号与质量契约入门正文

学习范围 · 单调时钟；采样时间；丢样；质量标志；CSV 与版本信息

用于控制的数据时刻应尽量代表实际采样时刻，而不是串口打印时刻。数据经 DMA、队列和网络转发后，收到它的时间已经包含等待。把采样时间和接收时间分开记录，才能估计延迟，判断某个旧样本是否还可用于当前决策。

周期和间隔用单调时钟计算；人类可读日期可以用于对齐运行记录。时钟回绕需要按计数器位宽处理，无符号差分仅在已约定的回绕范围内有效。重启后序号可能重置，日志应带 boot_id 或 session_id，不能把两次启动当成一条连续采样序列。

CSV · 示例字段，不是板上实测数据
命令与代码
session_id,seq,t_sample_us,adc_raw,temperature_c,quality,config_id
sim-001,0,0,2048,25.0,VALID,cal-v1
sim-001,1,100000,2050,25.1,VALID,cal-v1
sim-001,3,300000,0,,SENSOR_INVALID,cal-v1

上面的序号 2 缺失，应记录 GAP；第三条没有有效温度，不能填 0°C 继续送入控制器。质量标志可区分有效、超范围、过期、丢样、校准失效。算法除了输入值，也应接收有效性和数据年龄。

B23-M08标定、统计与异常数据处理入门正文

学习范围 · 两点标定；偏置；方差；中值与 MAD；异常标志；数据分割

两点线性标定先确定斜率 a=(y2−y1)/(x2−x1)，再求偏置 b=y1−a·x1，得到 y=a·x+b。参考仪器也有误差；使用更多点检查非线性、温漂和重复性。拟合所用数据与验证所用数据分开，才能判断标定是否能迁移到新工况。

Python · 基础样本统计，只用标准库

对尖峰可使用中值和 MAD：MAD=median(|x−median(x)|)。MAD 为零时不能直接做除法，应有由传感器噪声和分辨率定义的最低尺度。阈值不是通用常数：启动升温、真实碰撞和传感器断线可能都会产生大变化，结合物理范围、变化率和质量标志判断。

B23-M09重采样与滤波：平滑背后的延迟入门正文

学习范围 · 采样定理；混叠；EMA；FIR/IIR；分块状态；因果与离线滤波

采样率改变前先考虑信号带宽。高频成分一旦在 ADC 采样时混叠，后续数字滤波无法把它唯一恢复。降低已有数字数据的采样率时，先低通，再抽取；带抗混叠滤波的重采样函数能帮助离线验证，但它不能补救采集端已经发生的混叠。

指数平滑只需一个状态：y[k]=αx[k]+(1−α)y[k−1]。0<α≤1，α 越小通常越平滑、响应越慢。以时间常数 τf 选取 α=1−exp(−Ts/τf)，可以让参数带有时间尺度；这对应单极点离散形式，实际响应仍需测量。

Python · 单状态因果滤波
命令与代码

ts, tau_filter = 0.1, 0.5
alpha = 1.0 - math.exp(-ts / tau_filter)
filtered = first_valid_sample
for sample in valid_samples:
    filtered += alpha * (sample - filtered)

离线前后向滤波能使用未来样本，适合某些分析任务；在线控制不能照搬。先比较噪声标准差、阶跃延迟，再把滤波延迟计入闭环。只追求曲线平滑，可能让控制器来不及响应。

B23-M10特征提取、频谱与带迟滞的事件检测入门正文

平均值、峰峰值和 RMS 描述不同现象。含直流信号的 RMS 同时包含偏置和波动；诊断交流振动时，先明确是否去均值。对 N 个样本，RMS=sqrt(Σx²/N)。窗口长度不仅影响统计波动，还决定至少需要等多久才能形成一个完整特征。

B23-M11对象建模与阶跃辨识入门正文

学习范围 · 一阶模型；增益；时间常数；纯滞后；阶跃实验；模型残差

控制器面对的是物理对象。入门可以用一阶热模型：dT/dt=(Tamb+G·u−T)/τ。Tamb 是环境温度，G 是满占空比带来的稳态温升，τ 是时间常数。它忽略空间温差、非线性和传感器滞后，适合说明机制，不能未经验证就作为真实设备模型。

对已经接近稳态的对象施加输入阶跃 Δu，等新稳态后测 ΔT，得到局部增益 G≈ΔT/Δu。一阶无纯滞后模型在 τ 后完成最终变化的约 63.2%。若变化先等待 L 秒才开始，记录纯滞后 L，不要把它都塞进时间常数。

T(t)=T∞+(T0−T∞)·exp(−t/τ)
T∞=Tamb+G·u

本册仿真取 Tamb=25°C、G=60°C/占空比、τ=20 s。恒定 u=0.5 的理想稳态是 55°C，20 s 后约为 43.96°C。用这个解析解可检查离散仿真，而不是只看曲线像不像。

辨识数据要包括足够长的稳定段，保存输入变化时刻，避免输出限幅或严重饱和改变实验含义。用另一输入幅度或工况验证预测，画残差并检查其是否随温度、速度或负载变化。偏差过大时需要改模型或限制使用范围。

一个时间常数，为什么还没到稳态？

恒定输入 u=0.5 时，稳态是 25+60×0.5=55°C。解析解 T(t)=55−30·exp(−t/20)；20 秒只完成总变化的 63.2%，所以 T(20)=43.96°C。以下曲线来自这个解析模型，不是硬件实测。

B23-M12离散控制、采样周期与实时预算入门正文

学习范围 · 零阶保持；离散模型；固定周期；抖动；数据年龄；执行延迟

连续对象由离散控制器驱动，执行器通常在两个更新之间保持输出。对上一章的一阶模型，保持 u 时可精确写成 T[k+1]=a·T[k]+(1−a)(Tamb+G·u[k])，其中 a=exp(−Ts/τ)。这个式子是本册温控仿真的对象更新方式。

控制采样周期小于对象变化尺度是起点，但“某个固定比例”不能保证闭环稳定。模型滞后、计算延迟、滤波和控制器带宽共同影响设计。采样变快还会增加 CPU、总线和日志负担；应通过离散模型、频域分析和实验逐步确定。

Python · 恒定占空比的一阶精确更新
命令与代码

temperature = a * temperature + (1.0 - a) * (ambient + gain * duty)

积分更新使用的 dt 必须与控制设计一致：固定周期实现以规定周期运行并检测超时；变周期实现用有效时间差，并专门分析异常长间隔。遇到过期数据、负时间差或明显超时，应走已定义的降级逻辑，不能把巨大 dt 直接乘进积分。

B23-M13PI/PID：限幅、抗饱和与交互实验入门正文

学习范围 · 比例与积分；条件积分；执行器饱和；微分滤波；整定；仿真比较

比例项 P=Kp·e 立即响应误差；积分项按 I←I+Ki·e·Ts 累积持续误差。这里积分状态 I 已经包含 Ki，不能在输出处再乘一次 Ki。u=clip(P+I,0,1)。对于温控，Kp 的单位是占空比/°C，Ki 是占空比/(°C·s)。

当执行器已经满功率，继续累加正误差不会增加真实输出，却会储存很大的积分。设定值回落后，输出可能仍长时间饱和。条件积分在候选输出超出上限且误差继续向上推动时暂停积分；下限对应处理。误差把输出拉回范围时允许积分更新。

Python · 条件积分核心；完整仿真见 thermal_pi.py
命令与代码
candidate = integral + ki * error * dt
proposal = kp * error + candidate
pushing = (proposal > 1 and error > 0) or (proposal < 0 and error < 0)
if not (anti_windup and pushing):
    integral = candidate
output = min(1, max(0, kp * error + integral))

B23-M14状态估计与传感器融合入门入门正文

学习范围 · 预测与观测；互补滤波；标量卡尔曼；Q/R；创新；异常观测

滤波可以平滑读数，状态估计还利用动态模型推断没有直接测量的量。例如位置传感器给位置，模型帮助估计速度。互补滤波按频段组合信息；线性卡尔曼滤波按模型和噪声假设，在预测与观测之间分配权重。

先理解一个标量随机游走模型。状态预测保持 x 不变，预测方差 Pp=P+q·Ts。观测 z 的噪声方差为 R，增益 K=Pp/(Pp+R)，状态更新 x←x+K(z−x)。R 大时更信预测，预测不确定度大时更信观测；q 与 R 都是有单位的方差参数。

Python · 一维示意，要求 P≥0、q≥0、R>0、Ts>0
命令与代码
predicted_p = p + q * ts
innovation = measurement - estimate
k = predicted_p / (predicted_p + r_variance)
estimate += k * innovation
p = (1-k)**2 * predicted_p + k*k * r_variance

上面协方差更新采用标量 Joseph 形式。矩阵系统还需要状态转移、观测矩阵、控制输入，以及与采样周期相匹配的 Q。软件默认矩阵不能替代模型。观测时间不对齐、安装方向错误和偏置未处理，往往比调增益更先影响效果。

记录创新 z−预测观测及其统计。持续偏移可能来自模型或偏置，单个巨大创新可能来自异常观测。拒绝观测时只进行预测并保留不确定度增长，不能把丢失观测写成零。融合结果必须和保留的独立参考一起评价。

B23-M15前馈、串级与运动轨迹的工程入口入门正文

学习范围 · 前馈与反馈；内外环；带宽分配；斜率限制；加速度与执行器约束

反馈根据误差修正，前馈根据已知目标或扰动提前提供所需输出。若热模型稳态 T=Tamb+G·u，则目标 r 的名义前馈为 (r−Tamb)/G，再由反馈修正模型误差。环境温度变化时，前馈能减少等待误差累积的过程，但错误模型也会直接带来错误输出。

前馈和反馈的总和仍要经过实际执行器约束，抗饱和应依据真正送给对象的输出处理。只限制 PI 单独的输出而忽略相加后的饱和，会重新引入积分问题。电机驱动中的电流限幅、驱动器内部环和电源电压变化也需要纳入接口。

串级把快内环和慢外环组合，例如电流环、速度环、位置环。先验证内环，再设计外环，并测量实际延迟。外环直接把一个尚未稳定的内环当成理想执行器，会使调试很难解释。带宽应有足够分离，但具体比例由对象和采样条件决定。

Python · 设定值斜率限制，rate 的单位是物理量/秒
命令与代码
max_change = rate * ts
change = target - limited_reference
limited_reference += min(max_change, max(-max_change, change))

斜率限制可减轻突变请求。运动系统还应限制加速度，必要时限制 jerk；位置、速度和加速度边界都要与机械能力匹配。以路径规划或 MPC 为下一阶段时，先掌握模型、状态、约束和在线计算预算。

轨迹是随时间的函数

只计算 min(vmax, sqrt(a·距离)) 得到的是峰值速度，不是完整轨迹。对零起终速度的对称运动，先判断能否达到 vmax：若距离≤vmax²/a，使用三角速度；否则使用加速—匀速—减速。完整分段位置函数和端点断言见 labs/control_checks.py。验收位置连续、末端达到目标、峰值不超限；真实电机还要考虑加加速度、负载与限位。

检查结果

总输出约束有效；说明前馈依赖哪个模型；轨迹参数有明确单位。

B23-M16数据回放、自动指标与故障注入入门正文

学习范围 · 黄金输入；确定性回放；IAE；超调；整定时间；故障测试；数据隔离

每次改算法，都重跑同一份输入和配置，再比较结果。黄金输入不是永远正确的现实，而是一组版本化的回归场景。保留正常、边界、历史失败和新工况，避免调参数只适配一条好看的曲线。

指标含义必须明确
IAE∫|r−y|dt，离散时按间隔累计时间区间、物理量单位、丢样处理
超调响应超过指定目标的程度目标阶跃与参考幅度；目标回落另算
整定时间进入误差带后保持到观察结束误差带与观察窗口；未进入则未整定
饱和时长输出达到限制的累计时间上下限、容差及是否排除启动段
故障响应故障到安全动作的时间故障判定点、采样与输出测量点

实验场景至少包括目标变化、环境扰动、不可达目标、传感器失效、过期样本和计算超时。模型内的 fault 标志可以验证逻辑；硬件验证还需实际注入断线、丢帧和驱动故障，并量测输出，不能只检查一条日志字符串。

数据用于辨识和整定时，保留独立验证工况。连续相邻片段常有强相关性，随机分割容易让相似数据同时进入训练和验证。按设备、时间段或运行批次划分，记录每次参数搜索范围。

指标必须带时基

IAE=∫|r−y|dt，温控的单位是 °C·s。等间隔矩形近似为 Σ|e[k]|Ts；非等间隔可用梯形积分，必须读取实际时间戳。直接 Σ|e| 只在约定 Ts=1 时才等于该近似。以 e=1°C、时长2s 为例，IAE=2°C·s；采样加密不应把结果翻倍。实验中的这个性质测试用于识别遗漏 Ts 的错误。

指标脚本可重复；故障后输出为零并锁存；仿真与实测结果分别归档。

B23-M17综合实战：可回放的温控闭环入门正文

学习范围 · Python 仿真；CSV；PI 参数；抗饱和对比；故障关闭；C 移植

先完成一个不需要硬件的闭环。下载本册 thermal_pi.py，使用 Python 3.10 或更新版本运行。脚本只依赖标准库，每次生成 120 s 的确定性模型数据与指标；它不读传感器，也不控制真实输出。

终端 · 在下载目录运行
命令与代码
python thermal_pi.py --scenario normal --out normal.csv
python thermal_pi.py --scenario cooling --out cooling.csv
python thermal_pi.py --scenario recovery --anti-windup on --out recovery-on.csv
python thermal_pi.py --scenario recovery --anti-windup off --out recovery-off.csv
python thermal_pi.py --scenario sensor-fault --out fault.csv

先核对 normal：5 s 时由 25°C 请求 45°C，观察输出和最终误差。cooling 在 60 s 将环境温度降到 20°C；recovery 在 5～60 s 请求 95°C，然后回到指定目标；sensor-fault 在 70 s 锁存故障。每个 CSV 记录时间、目标、温度、输出、积分、未限幅输出和故障标志。

本环境已运行默认模型、饱和恢复和故障场景，并将 Python 与网页模型逐采样对照。默认 normal 的最终误差约 −0.00068°C，只反映理想无噪声模型。真实系统的分辨率、传感器延迟、执行器和散热变化都会改变结果。

B23-M18迁移实战：电机调速与振动数据诊断入门正文

学习范围 · 编码器速度；低速量化；速度 PI；限流；振动特征；多率任务；扩展方向

把温度换成速度，闭环结构仍然成立，但采样、驱动和模型需要重新建立。若编码器每转有效计数为 C，在窗口 Ts 内变化 Δn，转速 RPM=60·Δn/(C·Ts)。C 必须包含实际解码倍率；计数器回绕、方向和齿轮比也要统一。

低速短窗口可能连续多次得到零计数，然后突然跳变。可增加窗口或用相邻边沿周期估计速度，但前者增加延迟，后者需要处理超时和停转。根据速度范围选择方法，记录估计年龄；不能把未到新边沿当成无限保持旧速度。

先建立局部电机模型和驱动输出方向，再做速度 PI、斜率限制与输出限幅。电流限值、欠压、堵转及编码器失效进入故障状态机。带功率驱动的调试还需要器件额定范围和实际保护；本册附带代码只完成主机算法验证。

振动采样可以与速度控制使用不同频率。按稳定运行段计算交流 RMS、频带能量和峰值；改变转速会移动与转频相关的谱线，固定频率阈值可能误报。记录转速、负载、安装方式和采样设置，并按不同设备与工况留出验证数据。

完成这一项目后，可继续研究状态空间、LQR、MPC、机器人定位与规划、FOC、在线系统辨识和数据驱动诊断。进入这些方向前，先验证现有链路的数据质量、模型、实时预算和故障边界。
