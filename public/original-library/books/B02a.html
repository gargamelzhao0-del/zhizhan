C++ 标准库头文件通常不带 .h：stdio.h → <cstdio>、stdlib.h → <cstdlib>。<iostream> 是 C++ 独有的。

1.3 命名空间：std:: 是什么

C++ 标准库的东西都放在 std 命名空间里，所以写 std::cout。 命名空间是为了避免名字冲突——大型工程里两个模块都叫 log 也不会打架。

ns.cpp — 自定义命名空间 C++ 
#include <iostream>

namespace gpio {                    // 给这批名字分组
    int pin = 13;
    void high() { std::cout << "pin " << pin << " -> HIGH\n"; }
}
namespace uart {
    int pin = 17;                   // 同名 pin，互不冲突
}

int main()
{
    gpio::high();                   // 用 命名空间::名字 访问
    std::cout << "uart pin = " << uart::pin << "\n";
    return 0;
}
⚠ 别在头文件里写 using namespace std;

using namespace std; 会把整个 std 的名字"倒进"全局，极易冲突。头文件里绝对不要；源文件里偶尔图方便可以，但更推荐 using std::cout; 这种精确引入。

Module 02 · 引用

引用与 const

引用是 C++ 比 C 更好用的第一件武器：它是变量的"别名"，既能像指针一样避免拷贝，又没有指针的许多坑。 const 则把"这块数据不该被改"写成编译期约束。

◷ 约 55 分钟◈ 引用 vs 指针 · const⚑ 少写 * 和 &

2.1 引用：变量的别名

reference.cpp — 引用参数与别名（可运行） C++ 
#include <iostream>
#include <string>

void add_one(int &x) { x += 1; }          /* 引用参数：直接改实参 */
void print(const std::string &s) {        /* const 引用：不改，也不拷贝 */
    std::cout << "print: " << s << "\n";
}
int main()
{
    int n = 5;
    add_one(n);                            /* 传引用，行为像传变量本身 */
    std::cout << "n = " << n << "\n";

    int &r = n;                            /* r 是 n 的别名 */
    r = 42;
    std::cout << "n via ref = " << n << "\n";

    std::string msg = "hello reference";
    print(msg);
    return 0;
}

2.2 用 const 引用避免拷贝

传大对象（字符串、结构体、容器）时，按值传会复制一份，很贵。 传 const T&：既不拷贝、又保证函数不会改它——这是 C++ 里最常用的参数形式。

◆ 参数传递的三档
  • f(int x)：小类型，按值传（拷贝也便宜）。
  • f(const T& x)：大对象只读，不发拷贝、不可修改（首选）。
  • f(T& x)：需要修改调用方的大对象时用。

2.3 const 正确性：把"只读"写进类型

const_demo.cpp — 各种 const C++ 
#include <iostream>

int main()
{
    const int MAX = 100;          /* 常量：不能再赋值 */
    // MAX = 200;                 // ✕ 编译错误

    int a = 1, b = 2;
    const int *p = &a;            /* 指向的内容不可改（指针可变） */
    // *p = 5;                    // ✕
    p = &b;                      /* ✔ 指针本身可以改指向 */

    int *const q = &a;            /* 指针本身不可改（内容可变） */
    *q = 9;                       /* ✔ */
    // q = &b;                    // ✕

    std::cout << "MAX=" << MAX << " a=" << a << " *p=" << *p << "\n";
    return 0;
}
⚠ const 的位置有讲究

const int *p：内容只读（p is a pointer to const int）；int *const p：指针本身只读（p is a const pointer to int）。记法：从右往左读，const 挨着谁就限制谁。

◆ 重载的判据

重载靠参数列表区分（个数/类型/顺序），不能只靠返回值不同重载。调用哪个在编译期就定下来了。

3.2 默认参数

给参数一个默认值，调用时可以省略。规则：默认参数必须从右往左连续（不能再有非默认参数跟在它后面）。 上例 greet() 用默认值 "world"，greet("C++") 覆盖它。

类与对象

这是 C++ 最核心的一节：类把"数据"和"操作数据的函数"打包成一个自定义类型，对象是它的一个实例。 构造/析构、封装、this——理解这些，才算真正进入 C++。

◷ 约 70 分钟◈ 构造/析构 · 封装 · this⚑ C++ 的核心

4.1 一个类：数据 + 操作

class.cpp — 类/构造/析构/封装（可运行） C++ 
#include <iostream>
#include <cstdint>

class Counter {
public:
    Counter(int start) : value_(start) { std::cout << "构造: " << value_ << "\n"; }
    ~Counter() { std::cout << "析构: " << value_ << "\n"; }

    void inc() { ++value_; }                 // 成员函数可改私有成员
    int value() const { return value_; }     // const 成员函数：不修改对象

private:
    int value_;                              // 私有：外部不能直接改
};

int main()
{
    Counter c(10);
    c.inc();
    c.inc();
    std::cout << "value = " << c.value() << "\n";
    // c.value_ = 99;                        // 错误：value_ 是 private
    return 0;                                // main 结束时自动调用析构
}

4.3 封装：public 与 private

4.4 this 与成员初始化列表

point.cpp — 初始化列表与 this C++ 
#include <iostream>

class Point {
public:
    Point(int x, int y) : x_(x), y_(y) {}     // 初始化列表：直接初始化成员
    Point &move(int dx, int dy) {             // 返回 *this，支持链式调用
        x_ += dx; y_ += dy;
        return *this;
    }
    void print() const { std::cout << "(" << x_ << ", " << y_ << ")\n"; }
private:
    int x_, y_;
};

int main()
{
    Point p(0, 0);
    p.move(1, 2).move(3, 4);                  // 链式调用
    p.print();
    return 0;
}
◆ 初始化列表 : x_(x), y_(y)

运算符重载与友元

让自定义类型也能用 + - == << 这些运算符，代码读起来就像在操作内置类型。 这一节讲运算符重载的基本写法，以及 friend 友元。

5.1 重载 + 与 <<

operator.cpp — 让 Vec2 能做加法、能 cout（可运行） C++ 
#include <iostream>

struct Vec2 {
    double x, y;
};
Vec2 operator+(const Vec2 &a, const Vec2 &b) {     /* 重载 + */
    return Vec2{a.x + b.x, a.y + b.y};
}
std::ostream &operator<<(std::ostream &os, const Vec2 &v) {   /* 让它能 cout */
    return os << "(" << v.x << ", " << v.y << ")";
}

int main()
{
    Vec2 a{1, 2}, b{3, 4};
    Vec2 c = a + b;                                 /* 用起来像内置类型 */
    std::cout << "a + b = " << c << "\n";
    return 0;
}

◆ 运算符重载的几条常识
  • 不能发明新运算符，也不能改优先级/结合性；只能给已有运算符对自定义类型定义行为。
  • 至少一个操作数是自定义类型（不能给两个 int 重载 +）。
  • operator<< 写成返回 ostream& 的自由函数，才能链式 cout << a << b。
  • 不是所有运算符都该重载——只在语义自然时（如向量加）才做。

5.2 成员运算符与友元

member_op.cpp — 成员 operator== 与 friend operator+ C++ 
#include <iostream>

class Money {
public:
    explicit Money(int cents) : cents_(cents) {}
    bool operator==(const Money &o) const { return cents_ == o.cents_; }   // 成员运算符
    friend Money operator+(const Money &a, const Money &b);                 // 声明友元
    friend std::ostream &operator<<(std::ostream &os, const Money &m);
private:
    int cents_;
};
Money operator+(const Money &a, const Money &b) { return Money{a.cents_ + b.cents_}; }
std::ostream &operator<<(std::ostream &os, const Money &m) { return os << m.cents_ << " 分"; }

int main()
{
    Money a(120), b(80);
    std::cout << "a + b = " << (a + b) << "\n";
    std::cout << "a == b ? " << (a == b ? "yes" : "no") << "\n";
    return 0;
}
◆ 友元 friend 是什么

friend 声明允许某个外部函数访问类的 private 成员。 因为 operator+ 需要读两边的私有 cents_、又要写成自由函数（才能两个操作数对称），所以用友元。 友元是"破封装"的例外，能不用就不用。

5.3 与嵌入式的关系

⚠ 运算符重载本身零开销，但别滥用

重载只是"换个写法调用函数"，调用本身不引入额外开销。但"返回值运算符"（如本例返回 Vec2）可能产生临时对象、也可能没被内联——重载不保证比手写函数更快，取决于写法与优化。此外要注意：语义要自然（矩阵乘用 *、向量加点用 + 合理；用 + 表示"发送数据"就令人困惑）。嵌入式里常见的合理重载是：定点数/时间/单位的运算、位标志的 | &。

#include <string>

6.2 多态：virtual 与运行期分派

polymorphism.cpp — 抽象基类 + 多态（可运行） C++ 
#include <iostream>
#include <vector>
#include <memory>

class Shape {
public:
    virtual double area() const = 0;          /* 纯虚：抽象类 */
    virtual ~Shape() = default;
};
class Circle : public Shape {
    double r_;
public:
    explicit Circle(double r) : r_(r) {}
    double area() const override { return 3.14159 * r_ * r_; }
};
class Rect : public Shape {
    double w_, h_;
public:
    Rect(double w, double h) : w_(w), h_(h) {}
    double area() const override { return w_ * h_; }
};

int main()
{
    std::vector<std::unique_ptr<Shape>> shapes;
    shapes.push_back(std::make_unique<Circle>(2.0));
    shapes.push_back(std::make_unique<Rect>(3.0, 4.0));
    for (const auto &s : shapes)               /* 通过基类指针多态调用 */
        std::cout << "area = " << s->area() << "\n";
    return 0;
}

容器、算法与迭代器深化

依据布局、失效规则和资源上限选择容器与算法。

前置：本册前面的类型、函数与资源管理阅读约 15–25 分钟；实践约 30–60 分钟（规划估计）

机制与契约

vector 连续存储，随机访问 O(1)，增长可能重新分配；map 保持有序，unordered_map 依靠哈希且最坏情况不能按平均 O(1) 承诺。容器选择要同时考虑元素上限、分配、索引需求和迭代器失效。vector 扩容后地址可能变化，即使迭代器看起来仍指向某个数，也不能继续使用。排序后元素位置改变；索引也不等于稳定对象身份。

std::ranges::sort(v);

边界与误用
