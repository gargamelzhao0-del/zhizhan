Module 01 · 时钟与引脚基础

时钟树与启动.

“代码明明没错，外设就是不动”——在 STM32 上多半是时钟没开或时钟不对。本章讲清 HSE/HSI→PLL→SYSCLK→AHB/APB 的分频与耦合点（Flash 等待周期、APB1 定时器 ×2），并用 MCO 验证。

前置：了解寄存器读写与 C 语法，认识时钟源、分频、外设使能等概念。◷ 约 44 分钟◈ STM32F103 / ESP32 / STM32H7 三平台对照⚑ 主机模型；目标构建与测量按章验收能力目标：能配置 HSE→PLL×9=72 MHz 与 AHB/APB 分频，设置 Flash 等待周期并用 MCO 验证时钟。
本章速览
  • 外设不动先查时钟：RCC 使能 + 总线分频 + Flash 等待周期三件事。
  • HSE 起振必须带超时并回退 HSI，绝不死等。
  • 72/240/480 MHz 是三种设计，验证都靠回读（MCO/API），不靠假设。

1.1 时钟树：从晶振到外设

上电默认用内部 HSI(8 MHz)，启动文件调用 SystemInit，由你把 HSE(8 MHz 晶振) 起振、经 PLL ×9 得到 72 MHz SYSCLK，再切成 AHB 72 / APB2 72 / APB1 36 MHz。每个外设默认时钟关闭，必须先写 RCC_APBxENR 使能。

1.3 三平台对照：时钟初始化

同一件事在三平台写法不同：F103 配 RCC 寄存器；ESP32 用 IDF 时钟 API；H7 的 RCC 更复杂（多域、VOS）。三份代码均已交叉编译通过。

7.5 常见误区与排障

失败路径与排障
  • ORE 不处理：漏读 DR，接收通道“假死”。
  • BRR 直接截断：不四舍五入，误差翻倍，长帧末端错位。

Module 13 · 存储与复杂外设

存储器与文件系统接口.

存储的第一个事实是擦写粒度：“改一个字节”实际是“读整块→改→擦→写回”。掉电原子性靠提交标记（未提交=0xFFFF，已提交=0xA5A5，只清位合法），并以回读校验为准。

本章速览
  • Flash 只能把位从 1 写成 0：提交标记用“擦除态→魔数”。
  • 区分“写入完成”和“已持久化”，持久化以回读校验为准。
  • 关注擦写粒度与寿命；NVS/LittleFS 已封装掉电安全。

13.1 擦写粒度与提交标记

内部 Flash 按页/扇区擦除、字节可编程但不能反复覆写；外部 NOR 按 4 KB 擦、字节写；NAND/SD 按块擦。所以“改一个字节”= 读整块→改→擦→写回。掉电原子性靠提交标记：最后写 valid，未写即视为无效。

17.5 常见误区与排障

失败路径与排障
  • CAN 无终端电阻：反射导致误码、错误计数上升。
  • RS-485 一收完就拉低 DE：应等 TC，否则尾字节残缺。
  • Modbus 无帧间静默：粘包被当成一帧，解析错乱。
  • 1-Wire 时序不够：位时隙太短/太长，从机不应答。
◆ 自测 · Module 17（先答再看）

  1. CAN 与 RS-485 都差分、都抗干扰，为什么 CAN 能多主而 RS-485 通常一主多从？

    查看答案

    CAN 在协议层有非破坏性仲裁（按 ID 逐位竞争）与错误管理；RS-485 只是电气层，多主冲突需应用层解决，故常见 Modbus 主从轮询。

  2. RS-485 什么时候才能拉低 DE？

    查看答案

    要等 TC（发送完成）而不是 TXE，否则最后几位移出不完整，从机收到残缺数据。

  3. Modbus RTU 如何分帧？

    查看答案

    靠帧间静默（3.5 字符）分帧，再用 CRC16 校验帧完整性。没有静默会把粘连的帧当成一帧。

Module 21 · 无线通信

OTA 与网络升级、回滚.

OTA 把“升级”做成一条可失败、可回滚的链路：分块写备用分区→整包校验→切换启动→失败回滚。关键是断电安全：任何一步断电，设备都必须还能启动。

    查看答案

    不能。CRC 只防传输/存储误码，不防恶意篡改。安全场景必须用签名（验签）保证固件来源与完整性。

按“先定义、再结论”的方式收口；CTRL/CMD 在不同厂家的叫法差异也标注在此。

PLL / DIVM·DIVN·DIVP
锁相环。把低频晶振倍频到 CPU 频率；H7 用 DIVM/DIVN/DIVP 三个因子描述。
AHB / APB1 / APB2
片上总线与分频域。APB1 频率上限低于 APB2，外设挂在不同域上。
Flash 等待周期
高主频下取指需插入等待，F1 在 72MHz 需 LATENCY=2；配错会跑飞。
MCO
时钟输出引脚，把内部时钟引出来用频率计测量，用于“验证而非假设”。
推挽 / 开漏
推挽能主动输出高低；开漏只能拉低，高电平靠外部上拉，常用于总线。
BSRR / W1TS
原子置位/清除寄存器。写 1 生效，避免读-改-写竞态。
NVIC / 优先级分组
内核中断控制器与 AIRCR.PRIGROUP；数值越小优先级越高。
抢占 / 子优先级
同组内抢占决定能否打断，子优先级决定同时挂起时谁先执行。
PRIMASK / BASEPRI
内核专用寄存器，用 CPS/MRS/MSR 访问；BASEPRI 只屏蔽数值≥阈值的中断。
DMA / 通道·流
外设↔内存搬运器。F1 是固定通道，H7 是流+DMAMUX，ESP32 是描述符链表。
双缓冲 / 半满·全满
两块缓冲交替：一块在写、一块在处理；半满/全满中断提示切换。
cache 一致性
M7 等有 D-cache，DMA 写入的内存需 clean/invalidate，volatile 不能替代。
波特率 / BRR
异步串口的速率约定；BRR 由外设时钟除以波特率并四舍五入得到。
ORE 溢出错误
接收未及时读走又来新数据；不清 DR 会锁死后续接收。
时钟拉伸
I²C 从机把 SCL 拉低以争取时间；主机必须容忍。
掉电原子性 / 提交标记
用“擦除态→魔数”的只清位写法标记记录已提交，掉电最多丢一条。
枚举 / 描述符
USB 主机读设备描述符、分配地址、选择配置的过程；描述符必须 packed。
RTC 域
低功耗下仍供电的域，可保存现场并作为唤醒源（ESP32 RTC memory、STM32 备份域）。
