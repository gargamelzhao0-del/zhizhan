◆ 与 C 的三个关键差异
  • / 是真除法（7/2 = 3.5）；// 是地板除（向下取整）。与 C 的"整数除"差异要留意负数：Python 里 -7 // 2 == -4（向下取整），而 C 的 -7 / 2 == -3（向零截断）；-7 % 2 == 1（Python 取余符号跟除数走）。
  • 整数不溢出：Python 的 int 是任意精度（要多大有多大），所以在 MCU 上要留心"行为与 C 不同"。
  • f-string：f"{x:.2f}" 直接在字符串里嵌入表达式与格式。

Module 03 · 控制流

控制流：分支与循环

if/elif/else 做分支，for/while 做循环，break/continue 提前跳出。 与 C 类似，但 Python 用缩进分块、for 是"遍历"而非"计数"。

3.1 分支与两种循环

while n > 0:

    n -= 1

for x in range(1, 10):

    if x == 6:

◆ Python 的 for 是"遍历"
  • for i in range(1, 6)：range(a, b) 生成 a..b-1（含左不含右）。
  • 它遍历的是"可迭代对象"，不只是数字——可以直接 for x in [3,1,4]、for k in d（字典键）。
  • range(5) 是 0..4；range(1, 6) 是 1..5；range(0, 10, 2) 是偶数步进。
  • 负步长：range(5, 0, -1) 得到 5 4 3 2 1（含左不含右）；注意 range(5, 0)（步长为正）是空的——这正对应 C 里写 for(i=5;i>0;i--)。

术语

术语含义
解释器Python 是解释型语言：代码由解释器逐行执行，改一行即可运行，无需编译成可执行文件。
动态类型变量的类型在运行时确定；同一个名字可先后指向不同类型的对象（与 C 的静态类型不同）。
缩进Python 用缩进（通常 4 空格）表示代码块，代替 C 的花括号 {} —— 缩进错了就是语法错误。
列表list：[1, 2, 3]，可变、有序、可混类型；用 append/索引/切片操作。
元组tuple：(1, 2)，不可变的有序序列；可安全用作字典键。
字典dict：{"a": 1}，键值对（哈希表）；用 d[key] 访问、get 安全取值。
集合set：无序、不重复的元素集合；用于去重与交并差。
推导式comprehension：[x*x for x in xs if x%2==0]：一行生成列表/字典/集合。
函数def 定义函数；有参数、返回值；用 return 返回（无 return 返回 None）。
参数支持默认参数、关键字参数、可变参数（*args/**kwargs）；实参按名或按位置绑定。
作用域变量的可见范围：局部/全局；函数内改全局要 global（读则不必）。
类class 定义对象类型；__init__ 是构造方法；self 指向实例。
模块一个 .py 文件就是一个模块；用 import 引入；多个模块组成包（含 __init__.py）。
异常try/except/finally 处理错误；raise 抛出；与 C 的错误码不同，错误是"对象"。
迭代器可被 for 遍历的对象（实现 __iter__/__next__）；for 背后就是迭代器协议。
生成器用 yield 写出的惰性序列，按需产出值，省内存——适合处理大序列/流。

推导式推导式列表推导式，一行生成列表
