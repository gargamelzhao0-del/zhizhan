"RESULT: PASS" : "RESULT: FAIL"); return !ok;}

  1. 默认管道的退出码取自哪个命令？

    查看答案

    查看答案

    约定上表示命令成功。脚本据此判断成败；非 0 表示失败（具体值有不同含义）。
