Module 01 · 采样与标定

采样、时基与混叠.

采样第一原则：采样率 > 2×最高频率（Nyquist），否则高频会“混叠”成假低频。采样时基抖动同样引入误差。

前置：理解正弦/频率，会写 ADC 采样循环。◷ 约 44 分钟◈ 传感/DSP/控制对照⚑ 主机模型；目标构建与测量按章验收能力目标：能按 Nyquist 选采样率、设计前置抗混叠滤波并量化时基抖动影响。

采样条件比 Nyquist 口号更重要

Nyquist 条件针对带限信号。现实传感器的高频噪声仍可混叠，需要模拟抗混叠与适当采样。采样率 100 Hz 时，90 Hz 分量可能表现为 10 Hz；采集后再低通不能还原已经混叠的来源。实验应改变输入频率，查看采样序列和频谱。

本章速览
  • 采样率须 > 2×最高频率，否则混叠。
  • 抗混叠滤波放在 ADC 前。
  • 时基抖动与多通道同步要保证。

1.5 常见误区与排障

失败路径与排障
  • 采样率不足：混叠出假频率。
  • 无抗混叠滤波：带外噪声折叠进来。
  • 时基抖动：信噪比下降。
  • 多通道不同步：相位关系错。

Module 02 · 采样与标定

传感器标定与误差预算.

测量要“准”，就要做误差预算：把系统误差（偏置/增益）与随机误差分开，并逐项估算对结果的影响。

前置：理解线性函数与最小二乘，知道测量误差概念。◷ 约 44 分钟◈ 传感/DSP/控制对照⚑ 主机模型；目标构建与测量按章验收能力目标：能对传感器做增益/偏置标定、列误差预算并给出主导项与残差。
本章速览
  • 把系统误差（标定）与随机误差（滤波）分开。
  • 做误差预算找主导项。
  • 标定要覆盖范围并留残差。

2.1 系统误差与随机误差

系统误差（偏置/增益）用标定消除，随机误差用滤波/平均降低；两者处理方式不同，混在一起就无法针对性优化。误差预算把各项合成，找主导项。

2.2 真实证据：增益/偏置与残差

下面这段程序用最小二乘拟合 y=kx+b 得增益/偏置并检查残差：

host_calib.cC
/* host_calib.c —— 传感器标定：最小二乘拟合 y=kx+b 得增益/偏置与残差（主机可运行）。 * 编译运行：gcc -std=c11 -Wall -Wextra -O2 host_calib.c -o host_calib -lm && ./host_calib */#include <stdio.h>#include <math.h>int main(void) {    int ok = 1;    /* 标定点：真值增益 2.5、偏置 -1.0，叠加小噪声 */    double x[] = {0, 1, 2, 3, 4, 5};    double y[] = {-1.0, 1.4, 4.1, 6.3, 9.2, 11.4};    int n = 6; double sx = 0, sy = 0, sxx = 0, sxy = 0;    for (int i = 0; i < n; i++) { sx += x[i]; sy += y[i]; sxx += x[i]*x[i]; sxy += x[i]*y[i]; }    /* 最小二乘 y = k x + b：k=增益、b=偏置 */    double k = (n*sxy - sx*sy) / (n*sxx - sx*sx);    double b = (sy - k*sx) / n;    printf("标定 y=%.3f x + %.3f（期望增益≈2.5 偏置≈-1.0）\n", k, b);    if (fabs(k - 2.5) > 0.05 || fabs(b + 1.0) > 0.05) ok = 0;    /* 残差评估：最大绝对残差与残差 RMS，检查是否有系统趋势 */    double maxr = 0, ss = 0;    for (int i = 0; i < n; i++) {        double r = y[i] - (k*x[i] + b);        if (fabs(r) > maxr) maxr = fabs(r);        ss += r*r;    }    double rms = sqrt(ss/n);    printf("最大残差=%.3f 残差RMS=%.3f（阈值 ≤0.25）\n", maxr, rms);    if (maxr > 0.25) ok = 0;    printf("结论：增益/偏置由拟合得到，残差小且无系统趋势\n");    printf("\n%s\n", ok ? "RESULT: PASS" : "RESULT: FAIL");    return ok ? 0 : 1;}
