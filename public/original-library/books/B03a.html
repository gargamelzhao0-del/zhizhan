Module 02 · 所有权

所有权与移动

这是 Rust 最核心、也最独特的概念：每个值只有一个所有者。交出去叫"移动"，之后原变量就不能再用。 它一次消灭了"忘记释放 / 重复释放 / 释放后使用"一整类 bug。

◷ 约 65 分钟◈ move · Copy · Clone · Drop⚑ Rust 的地基

2.1 移动：交出去就不能再用

m02_ownership.rs — 移动/Copy/Clone（可运行） Rust 
#[derive(Clone)]
struct Buf { data: [u8; 4] }

fn consume(b: Buf) {                 // 取得所有权
    println!("consume 拿到 Buf, data[0] = {}", b.data[0]);
}

fn main() {
    let a = Buf { data: [1, 2, 3, 4] };
    consume(a);                      // a 被移动进 consume
    // println!("{}", a.data[0]);    // 取消注释会编译错误：a 已被移动

    let x = 5;                       // i32 是 Copy：赋值/传参是复制
    let y = x;
    println!("x = {}, y = {} (Copy: x 仍可用)", x, y);

    let s = String::from("hi");
    let t = s.clone();               // 需要复制堆数据时显式 clone
    println!("s = {}, t = {}", s, t);
}

FIG 2.1 移动：所有权像"接力棒"，同一时刻只有一个所有者
C 里 consume(a) 按值传会拷贝，两个都能用；Rust 是移动，交出去后原变量失效——释放责任随所有权转移，不可能重复释放。

2.2 Copy：哪些类型"赋值=c 复制"

内建标量（整数、浮点、bool、char）和共享引用 &T 是 Copy；它们的赋值/传参是按位复制，原变量仍可用（像 C）。注意：Copy 是"显式选择加入"的枚举/结构体——即使所有字段都是 Copy，只要不写 #[derive(Copy, Clone)]（或手写 impl Copy），它就不是 Copy，赋值默认仍是移动。（本例的 Buf 正是如此：[u8; 4] 是 Copy，但 Buf 没 derive，所以 consume(a) 会移动。）而 String/Vec 这类拥有堆内存的类型天生不能 Copy，只能是移动或显式 clone。

类型Copy？赋值时
i32/f64/bool/char是复制，原变量仍可用
String/Vec<T>/HashMap否移动（或显式 .clone()）
含非 Copy 成员的结构体否移动
⚠ 全量 clone 常常是"用错"的信号

到处 .clone() 能让代码编过，但可能付出不必要的复制（尤其大对象/嵌入式）。更好的做法往往是传引用（下一节 M03）。

2.3 Drop：离开作用域自动清理

值离开作用域时，Rust 自动调用它的 Drop（析构）——String 释放堆、文件句柄关闭、锁释放。 这就是 Rust 版的 RAII：你不用写 free，也不会忘。

Module 03 · 借用

借用与引用

总把值"移动"给函数太麻烦。更好的做法是借用：把引用传进去，函数用一下、不夺走所有权。 规则很简单：同一时刻要么多个只读、要么一个可写。

◷ 约 60 分钟◈ &/&mut · 借用规则⚑ 编译期防别名

3.1 共享借用与可变借用

m03_borrow.rs — & 与 &mut（可运行） Rust 
fn len(xs: &[i32]) -> usize { xs.len() }      // 共享借用（只读）

fn double_all(xs: &mut [i32]) {               // 可变借用（可写）
    for v in xs.iter_mut() { *v *= 2; }
}

fn main() {

fn longest<'a>(a: &'a str, b: &'a str) -> &'a str {   // 生命周期标注
    if a.len() >= b.len() { a } else { b }
}

fn main() {
    let nums = vec![1, 2, 3, 4, 5, 6];
    let evens_sq: Vec<i32> = nums.iter()
        .filter(|&&x| x % 2 == 0)      // 闭包捕获
        .map(|&x| x * x)
        .collect();
    println!("evens squared = {:?}", evens_sq);

    let add = |a, b| a + b;            // 闭包
    println!("add(2,3) = {}", add(2, 3));

}

◆ 'a 是什么

longest<'a>(a: &'a str, b: &'a str) -> &'a str 的意思是："返回值至少不超出 a、b 中较短者的存活范围"（编译器取两者生命周期的交集）。 编译器据此保证调用方拿到的引用不会指向已经释放的数据——正是 C 里悬垂指针的解药。很多情况下生命周期能自动推导，不必手写。

.iter()遍历（借用元素）

线程可以同时执行任务；Send/Sync 表达类型跨线程转移和共享的条件。示例用有界 sync_channel 传递拥有的数据，以队列容量形成背压；Arc<Mutex<T>> 共享受保护的状态，锁应只覆盖短操作。Future 是可被 poll 推进的状态机，async 函数被调用并不表示已经运行。取消常表现为 Future 被丢弃，但 Drop 不能自动证明真实 IO/DMA 已停止。

边界与误用

Rc 不能直接跨线程；Arc 也不自动让任意 T 线程安全。不要持锁等待另一个线程必须获得同一锁才能完成的事件。主机线程模型不能直接套到中断上下文。

术语

术语含义
所有权每个值有且只有一个所有者；所有者离开作用域即自动释放（drop）。这是 Rust 内存安全的核心。
移动move：把值的所有权交给别人，原变量不再可用（除非类型实现 Copy）。
Copy标记类型可「按位复制」（如整数、bool）；这类类型赋值不会移动、原变量仍可用。
借用不转移所有权的引用：&T 只读、&mut T 可写；同一时刻「多个只读」或「一个可写」，二选一。
生命周期引用必须不晚于它引用的数据失效；用 'a 标注，编译器据此拒绝悬垂引用。
枚举enum：一个类型取若干「变体」之一，每个变体可带数据；比 C 的枚举强大得多。
模式匹配match / if let：按值的形状分支并取出内部数据；必须穷尽所有情况。
OptionOption<T>：要么 Some(T)（有值）、要么 None（无值）；用类型表达「可能为空」，取代空指针。
ResultResult<T,E>：要么 Ok(T)、要么 Err(E)；Rust 用来替代异常/错误码的可恢复错误处理。
trait一组方法签名（接口）；类型 impl 某 trait 即「具备该能力」，可用于泛型约束。
结构体struct：把多个字段组合成自定义类型，配合 impl 定义方法。
泛型用类型参数写一套代码，适配多种类型；编译期为每种具体类型生成一份（单态化）。
迭代器Iterator：一系列值的惰性序列，用 map/filter/collect 等链式处理。
闭包|args| expr：能捕获环境变量的匿名函数，常配合迭代器使用。
crate编译单元/包；Cargo 管理依赖与构建，crate 是最小编译单位。
模块mod：给代码分组与命名空间；用 pub 控制对外可见性。
