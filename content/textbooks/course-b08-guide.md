## 单片机应用 开发实战

 

这本书回答的是： **需求怎么落到状态机、按键误触发、PID 积分饱和、电池几天就空、掉电丢配置** ——以及同一件事在  **STM32F103 / ESP32 / STM32H7**  三平台上怎么写、错在哪。内容从  **需求到架构、工程骨架、人机交互、数据存储** ，一路到  **控制、电源、自恢复、综合项目与产品验收** 。

 

**15** 模块 / 主题



**3** 平台



**7\+45** 运行 / 对照



**15** 机制图示

 

本文档的定位



面向 **会写 C、点亮过外设，但没完整做过一个可交付产品** 的开发者。默认你能操作 GPIO/定时器/串口，但对“状态机建模、参数持久化、低功耗预算、产品验收”只有模糊印象。



每一章都包含：机制图 → 可编译/可运行代码 →  **主机运行或真实交叉编译证据**  → 三平台对照 → 失败路径 → 自测。板上项一律标注“需上板”。

 

证据怎么读



状态机迁移、按键去抖、PID 抗饱和、功耗预算、掉电日志等数字来自 ` labs/host_*.c `（主机 ` gcc ` 真实运行，打印 ` RESULT: PASS `）；三平台实现另经真实交叉编译。
