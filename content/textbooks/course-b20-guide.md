## 传感器、信号处理 与控制

 

这本书回答的是： **采样混叠、滤波延迟搞不清、标定不准、融合发散、闭环振荡** ——问题分别落在采样时基、标定误差、滤波设计、状态估计与控制约束上。内容从  **采样混叠、标定、时域滤波、FIR/IIR、FFT** ，一路到  **特征、状态估计与融合、控制基础、PID 与执行器约束、采样到闭环** 。

 

**10** 模块 / 主题



**3** 环节



**6\+10** 运行 / 对照



**10** 机制图示

 

本文档的定位



面向 **会写 C、要做数据采集与闭环控制** 的开发者。默认你懂采样与中断，但对“混叠、滤波延迟、标定、融合、控制约束”不够系统。



每一章都包含：机制图 → 主机可运行的采样/滤波/控制模型 →  **真实运行证据**  → 环节对照 → 失败路径 → 动手练习 → 自测。

 

证据怎么读



混叠频率、均值/中值/EMA、FIR/IIR 差分方程、DFT 峰值、卡尔曼融合、PID 限幅等来自 ` labs/host_*.c `（主机 ` gcc ` 真实运行，打印 ` RESULT: PASS `）。
