| 主题 | 正确做法 | 常见错误 | 后果 |
| --- | --- | --- | --- |
| 系统调用 | 检查返回值 \+ errno | 忽略返回值 | 错误被当成功 |
| 读写 | 循环处理短读/短写 | 一次调用当完成 | 数据截断 |
| IPC | 有界队列 \+ 同步 | 无界 / 无同步 | 丢消息 / 错乱 |
| 网络 | 长度前缀分帧 \+ 半包 | 把 TCP 当消息 | 粘包解析失败 |
| 并发 | 互斥/原子/条件变量 | 无锁共享 | 偶发错值 |
| 服务 | init 托管 \+ 限速重启 | 裸跑 / 无限重启 | 无人拉起 / 风暴 |
| 配置 | 原子写(tmp→rename) | 直接覆写 | 掉电损坏 |
| 性能 | 预算 \+ 上界 \+ 降级 | 无预算 / 无降级 | OOM / 超期 |
| 升级 | 校验 \+ 回滚 | 无回滚 | 升级变砖 |
| 观测 | 日志/指标/健康检查 | 静默失败 | 现场无法定位 |
