## Python 语言基础 从零到能读《Python 嵌入式》

 

这一册把  **Python 当作一门语言从零讲** ：动态类型、控制流、函数、数据结构、字符串与文件、类与模块、异常与生成器、测试。 零基础也能读（会 C 更好理解"差异"）。学完它，你就能顺畅进入《Python（嵌入式向）》(B04)，用它做上位机工具与 MicroPython。 标 **「可运行」** 的示例都用本机 ` python `  **真实运行** （正文末尾附真实输出）；其余为补充片段。
