# 同一数据通路的跨平台分析

```zhizhan-anchor
capstone
```



把 10 章串成一条路径：ISA/调用 → 异常 → 内存层次 → MMU/[DMA](term:dma) → 内存序 → 性能预算，做同一数据通路的跨平台对比。



> ◈ 8 步分析路径 · ⚑ 每步可验收

 

把 10 章串成一条真实路径： **传感器采样 → 滤波 → 上报** ，在三类架构（Cortex-M / Cortex-A / RISC-V）上沿  **ISA → 访存 → cache → 保护 → 性能**  逐层量化，最后给出 **条件化结论** （在什么约束下选哪类架构）。

 

 
1. **① 分类与映射** （[M01](doc:course-b18-m01#m01)）——把每个缓冲/外设落到地址映射的哪个区；验收：` labs/host_memmap.c ` 译码输出可复述。
 
2. **② 调用与 ISA** （[M02](doc:course-b18-m02#m02)/[M08](doc:course-b18-m08#m08)）——滤波函数在 Arm/RISC-V 上的参数与指令；验收：能读懂 ` labs/abi_arm.s `。
 
3. **③ 异常与时基** （[M03](doc:course-b18-m03#m03)）——采样中断优先级与最坏嵌套栈；验收：栈按最坏深度预留。
 
4. **④ 访存与缓存** （[M04](doc:course-b18-m04#m04)/[M06](doc:course-b18-m06#m06)）——顺序 vs 跳跃访问成本；DMA 缓冲 clean/invalidate；验收：无旧数据。
 
5. **⑤ 保护与隔离** （[M05](doc:course-b18-m05#m05)）——MMU 权限 / MPU 区域；验收：越权访问被拒。
 
6. **⑥ 并发与内存序** （[M07](doc:course-b18-m07#m07)）——生产者/消费者 release/acquire；验收：读标志即见数据。
 
7. **⑦ 性能预算** （[M09](doc:course-b18-m09#m09)）——` 时间 = 指令数 × CPI ÷ 频率 `；验收：预算与实测同量级。
 
8. **⑧ 条件化结论** （[M10](doc:course-b18-m10#m10)）——在数据规模/实时性/功耗约束下给出选型；验收：结论有条件、有数据。
 

 

本册所有真实芯片的 cache/MMU/功耗为板上实测项；调用约定、访存成本模型、翻译/权限、内存序、CPI 预算等主机可验证部分已给出真实编译与运行结果（` labs/ `）。
