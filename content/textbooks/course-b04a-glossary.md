## 术语

 

| 术语 | 含义 |
| --- | --- |
| **解释器** | Python 是解释型语言：代码由解释器逐行执行，改一行即可运行，无需编译成可执行文件。 |
| **动态类型** | 变量的类型在运行时确定；同一个名字可先后指向不同类型的对象（与 C 的静态类型不同）。 |
| **缩进** | Python 用缩进（通常 4 空格）表示代码块，代替 C 的花括号 {} —— 缩进错了就是语法错误。 |
| **列表** | list：\[1, 2, 3\]，可变、有序、可混类型；用 append/索引/切片操作。 |
| **元组** | tuple：(1, 2)，不可变的有序序列；可安全用作字典键。 |
| **字典** | dict：{"a": 1}，键值对（哈希表）；用 d\[key\] 访问、get 安全取值。 |
| **集合** | set：无序、不重复的元素集合；用于去重与交并差。 |
| **推导式** | comprehension：\[x\*x for x in xs if x%2==0\]：一行生成列表/字典/集合。 |
| **函数** | def 定义函数；有参数、返回值；用 return 返回（无 return 返回 None）。 |
| **参数** | 支持默认参数、关键字参数、可变参数（\*args/\*\*kwargs）；实参按名或按位置绑定。 |
| **作用域** | 变量的可见范围：局部/全局；函数内改全局要 global（读则不必）。 |
| **类** | class 定义对象类型；\_\_init\_\_ 是构造方法；self 指向实例。 |
| **模块** | 一个 .py 文件就是一个模块；用 import 引入；多个模块组成包（含 \_\_init\_\_.py）。 |
| **异常** | try/except/finally 处理错误；raise 抛出；与 C 的错误码不同，错误是"对象"。 |
| **迭代器** | 可被 for 遍历的对象（实现 \_\_iter\_\_/\_\_next\_\_）；for 背后就是迭代器协议。 |
| **生成器** | 用 yield 写出的惰性序列，按需产出值，省内存——适合处理大序列/流。 |

## 符号 / 构件

 

| 符号 / 构件 | 类别 | 说明 |
| --- | --- | --- |
| ` print ` | 内置函数 | 打印到标准输出（可多参数、可 sep/end） |
| ` len ` | 内置函数 | 求序列/字符串/字典的长度 |
| ` range ` | 内置函数 | 生成整数序列：range(5) → 0..4 |
| ` f-string ` | 字符串语法 | f"x={x}"：把表达式嵌入字符串（Python 3.6\+） |
| ` def ` | 关键字 | 定义函数 |
| ` lambda ` | 关键字 | 匿名函数：lambda x: x\+1 |
| ` __init__ ` | 关键字/方法 | 定义类与构造方法（初始化实例属性） |
| ` self ` | 约定参数 | 类方法里指向当前实例的第一个参数 |
| ` import ` | 关键字 | 引入模块：import math / from math import sqrt |
| ` try / except ` | 异常 | 捕获并处理异常：try: ... except ValueError: ... |
| ` with open ` | 上下文管理 | 自动关闭文件：with open("f") as fh: |
| ` 推导式 ` | 推导式 | 列表推导式，一行生成列表 |
| ` yield ` | 关键字 | 在函数中产出生成器的一个值 |
| ` None ` | 常量 | 表示"没有值"（类似 C 的 NULL，但是常规对象） |
