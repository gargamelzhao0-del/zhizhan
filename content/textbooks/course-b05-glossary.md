按“先定义、再结论”的方式收口；CTRL/CMD 在不同厂家的叫法差异也标注在此。



PLL / DIVM·DIVN·DIVP



锁相环。把低频晶振倍频到 CPU 频率；H7 用 DIVM/DIVN/DIVP 三个因子描述。



AHB / APB1 / APB2



片上总线与分频域。APB1 频率上限低于 APB2，外设挂在不同域上。



Flash 等待周期



高主频下取指需插入等待，F1 在 72MHz 需 LATENCY=2；配错会跑飞。



MCO



时钟输出引脚，把内部时钟引出来用频率计测量，用于“验证而非假设”。



推挽 / 开漏



推挽能主动输出高低；开漏只能拉低，高电平靠外部上拉，常用于总线。



BSRR / W1TS



原子置位/清除寄存器。写 1 生效，避免读-改-写竞态。



NVIC / 优先级分组



内核中断控制器与 AIRCR.PRIGROUP；数值越小优先级越高。



抢占 / 子优先级



同组内抢占决定能否打断，子优先级决定同时挂起时谁先执行。



PRIMASK / BASEPRI



内核专用寄存器，用 CPS/MRS/MSR 访问；BASEPRI 只屏蔽数值≥阈值的中断。



[DMA](term:dma) / 通道·流



外设↔内存搬运器。F1 是固定通道，H7 是流\+DMAMUX，ESP32 是描述符链表。



双缓冲 / 半满·全满



两块缓冲交替：一块在写、一块在处理；半满/全满中断提示切换。



cache 一致性



M7 等有 D-cache，DMA 写入的内存需 clean/invalidate，volatile 不能替代。



波特率 / BRR



异步串口的速率约定；BRR 由外设时钟除以波特率并四舍五入得到。



ORE 溢出错误



接收未及时读走又来新数据；不清 DR 会锁死后续接收。



时钟拉伸



[I²C](term:i2c) 从机把 SCL 拉低以争取时间；主机必须容忍。



掉电原子性 / 提交标记



用“擦除态→魔数”的只清位写法标记记录已提交，掉电最多丢一条。



枚举 / 描述符



USB 主机读设备描述符、分配地址、选择配置的过程；描述符必须 packed。



RTC 域



低功耗下仍供电的域，可保存现场并作为唤醒源（ESP32 RTC memory、STM32 备份域）。
