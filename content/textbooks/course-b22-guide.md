## 嵌入式安全 与设备生命周期

 

这本书回答的是： **设备能被伪造/克隆、固件能被替换、通信能被窃听、升级能变砖、密钥泄露无法止损** ——问题分别落在威胁建模、密码学使用、身份与密钥生命周期、安全启动与通信/升级安全上。内容从  **资产/威胁/信任边界、密码学、身份与密钥** ，一路到  **安全启动、通信安全、升级回退、隔离最小权限、健壮性与安全测试、生产维护退役、可维护的安全设备** 。

 

**10** 模块 / 主题



**3** 防线



**6\+10** 运行 / 对照



**10** 机制图示

 

本文档的定位



面向 **做联网/可升级产品、需要安全基线** 的开发者/团队。默认你懂固件与通信，但对“威胁建模、密钥生命周期、安全启动、最小权限”不够系统。



每一章都包含：机制图 → 主机可运行的安全/生命周期模型 →  **真实运行证据**  → 三条防线对照 → 失败路径 → 动手练习 → 自测。本册为工程实践，不构成认证结论。

 

证据怎么读



威胁风险评分、HMAC 与篡改检测、密钥生命周期状态机、信任链逐级验签、最小权限能力、输入校验/模糊等来自 ` labs/host_*.c `（主机 ` gcc ` 真实运行，打印 ` RESULT: PASS `）；简化哈希仅用于演示流程，不代表密码学强度。
