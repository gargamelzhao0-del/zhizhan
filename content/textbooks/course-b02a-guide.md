## C\+\+ 语言基础 从零到能读《迁移地图》

 

这一册把  **C\+\+ 当作一门语言从零讲** ：类、封装、继承、多态、模板、STL、智能指针、异常——而不是"从 C 到 C\+\+ 的差异对照"。 前提是你会 C（读完 B00）。学完它，你就能顺畅读《C\+\+（嵌入式向）迁移地图》(B02)，把 C\+\+ 用到单片机上。 每个示例都用 ` g++ `  **真实编译并运行** 。

## C\+\+ 分支 · 读到能完成什么？



**写固定容量数据容器及资源句柄类，提供复制/移动策略、错误通道和独立构建测试。**



入门条件：C 的函数、数组、指针；若选择 C 路线可跳过整册。



首次阅读：[引用与 const](doc:course-b02a-m02#m02) → [类与对象](doc:course-b02a-m04#m04) → [模板与 STL](doc:course-b02a-m07#m07) → [智能指针、异常与 RAII](doc:course-b02a-m08#m08) → [对象生命周期与值语义深化](doc:course-b02a-m09#m09) → [容器、算法与迭代器深化](doc:course-b02a-m10#m10) → [构建、测试与库边界](doc:course-b02a-m12#m12)



按需延后：运算符重载、复杂继承、泛型技巧按接口需要学习；不要把语法数量当熟练度。
