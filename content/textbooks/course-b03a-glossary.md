## 术语

 

| 术语 | 含义 |
| --- | --- |
| **[所有权](term:ownership)** | 每个值有且只有一个所有者；所有者离开作用域即自动释放（drop）。这是 Rust 内存安全的核心。 |
| **移动** | move：把值的所有权交给别人，原变量不再可用（除非类型实现 Copy）。 |
| **Copy** | 标记类型可「按位复制」（如整数、bool）；这类类型赋值不会移动、原变量仍可用。 |
| **借用** | 不转移所有权的引用：&T 只读、&mut T 可写；同一时刻「多个只读」或「一个可写」，二选一。 |
| **生命周期** | 引用必须不晚于它引用的数据失效；用 'a 标注，编译器据此拒绝悬垂引用。 |
| **枚举** | enum：一个类型取若干「变体」之一，每个变体可带数据；比 C 的枚举强大得多。 |
| **模式匹配** | match / if let：按值的形状分支并取出内部数据；必须穷尽所有情况。 |
| **Option** | Option\<T\>：要么 Some(T)（有值）、要么 None（无值）；用类型表达「可能为空」，取代空指针。 |
| **Result** | Result\<T,E\>：要么 Ok(T)、要么 Err(E)；Rust 用来替代异常/错误码的可恢复错误处理。 |
| **trait** | 一组方法签名（接口）；类型 impl 某 trait 即「具备该能力」，可用于泛型约束。 |
| **结构体** | struct：把多个字段组合成自定义类型，配合 impl 定义方法。 |
| **泛型** | 用类型参数写一套代码，适配多种类型；编译期为每种具体类型生成一份（单态化）。 |
| **迭代器** | Iterator：一系列值的惰性序列，用 map/filter/collect 等链式处理。 |
| **闭包** | \|args\| expr：能捕获环境变量的匿名函数，常配合迭代器使用。 |
| **crate** | 编译单元/包；Cargo 管理依赖与构建，crate 是最小编译单位。 |
| **模块** | mod：给代码分组与命名空间；用 pub 控制对外可见性。 |

## 符号 / 构件

 

| 符号 / 构件 | 类别 | 说明 |
| --- | --- | --- |
| ` fn main ` | 入口函数 | 可执行程序的入口（fn 定义函数） |
| ` println! ` | 宏 | 格式化打印到标准输出（带 ! 表示宏，可带 {} 占位符） |
| ` let ` | 变量绑定 | let 定义不可变绑定；let mut 定义可变绑定 |
| ` match ` | 表达式 | 模式匹配分支，必须穷尽所有可能 |
| ` Some / None ` | 枚举变体 | Option\<T\> 的两个变体：有值 / 无值 |
| ` Ok ` | 枚举变体 | Result\<T,E\> 的两个变体：成功 / 失败 |
| ` ? ` | 运算符 | 错误传播：Ok 就取值继续，Err 就提前返回 |
| ` impl ` | 关键字 | 为类型实现方法或 trait（impl Type {} / impl Trait for Type {}） |
| ` trait ` | 关键字 | 定义一组方法签名作为接口 |
| ` #[derive(Debug)] ` | 属性/宏 | 自动为结构体/枚举生成 Debug 等实现（可 {:?} 打印） |
| ` Vec ` | 标准库集合 | 可增长的动态数组；push/size/下标访问 |
| ` HashMap ` | 标准库集合 | 键值哈希表；insert/get/entry |
| ` cargo run ` | 工具命令 | 编译并运行当前 crate |
| ` #[test] ` | 属性/宏 | 标记一个测试函数，cargo test 会运行它 |
