## 嵌入式 Linux 系统

 

这本书回答的是： **“内核起了但没到 init”“设备树写了但驱动不 probe”“升级一半掉电变砖”** ——这些问题分别落在启动链、设备树、根文件系统与升级/恢复上。内容从  **SoC 启动链、交叉编译与构建系统、设备树、内核、根文件系统、存储分区、系统调试** ，一路到  **板级移植与镜像交付、A/B 升级与恢复实战** ，并给出  **STM32MP1 / i.MX6ULL / Allwinner V3s**  三条参考路线对照。

本文档的定位



面向 **会写 C、跑过 MCU/RTOS，但没独立搭过嵌入式 Linux 系统** 的开发者。默认你了解外设与中断，但对“启动链怎么接力、设备树怎么匹配、rootfs 怎么最小、升级怎么不变砖”只有模糊印象。



每一章都包含：机制图 → 主机可运行的系统模型 →  **真实运行证据**  → 三条路线对照（DTS/U-Boot/Shell/配置片段，逐字与 labs 一致）→ 失败路径 → 动手练习 → 自测。板上项一律标注“需上板”，不把估算写成实测。

 

证据怎么读



启动日志分阶段、设备树匹配、Kconfig 冲突、rootfs 布局、cpio 打包、分区校验、日志等级、工具链一致性、Shell 分词等数字来自 ` labs/host_*.c `（主机 ` gcc ` 真实运行，打印 ` RESULT: PASS `）；三条路线的 ` .dts/.cmd/.sh/.cfg ` 片段全部来自 ` labs/ ` 并与正文逐字一致，Shell 片段另经 ` bash -n ` 语法检查。
