## 术语

 

| 术语 | 含义 |
| --- | --- |
| **源文件** | 你写的 .c/.h 文本文件；人可读，机器不能直接运行。 |
| **编译** | 把源文件翻译成机器能执行的中间产物/目标文件；编译器负责检查语法与类型。 |
| **链接** | 把多个目标文件与库拼成一个可执行文件；解决「谁调用了谁」。 |
| **变量** | 一块有名字、有类型的内存；类型决定它能存什么、占多少字节。 |
| **类型** | int/float/char 等，决定取值范围、精度与可用运算。 |
| **运算符** | 进行计算的符号：算术 \+ - \* / %、比较 == != \< \>、逻辑 && \|\| !、赋值 =。 |
| **控制流** | 决定「按什么顺序执行」的语句：if/else 分支、while/for 循环、break/continue。 |
| **函数** | 把一段逻辑命名、可重复调用；有参数、返回值和自己的作用域。main 是程序入口。 |
| **作用域** | 名字可见的范围。局部变量只在它所在的花括号内有效，出了范围就销毁。 |
| **数组** | 一排同类型元素，用下标访问；下标从 0 开始，越界是未定义行为。 |
| **字符串** | C 里是以 结尾的字符数组；操作靠 \<string.h\> 的函数。 |
| **指针** | 保存「地址」的变量；& 取地址、\* 解引用。它是 C 与硬件打交道的核心。 |
| **结构体** | 把多个不同类型的数据打包成一个新类型（struct），表示一条「记录」。 |
| **头文件** | 放声明（函数原型、类型、宏），被多个 .c 用 #include 引入；用 include guard 防重复。 |
| **Makefile** | 描述「目标—依赖—命令」的构建脚本，让 make 只重编改动过的文件。 |

## 符号 / 构件

 

| 符号 / 构件 | 类别 | 说明 |
| --- | --- | --- |
| ` #include ` | 预处理指令 | 把别的文件内容引入本文件（如 \<stdio.h\>） |
| ` #define ` | 预处理指令 | 定义宏/常量（如 #define N 10） |
| ` printf ` | 标准库函数 | 格式化输出到屏幕（\<stdio.h\>） |
| ` scanf ` | 标准库函数 | 从输入读取并解析（注意用 & 取地址） |
| ` int main(void) ` | 程序入口 | 程序从 main 开始执行；返回 0 表示成功 |
| ` sizeof ` | 运算符 | 求类型/变量占用的字节数（编译期） |
| ` NULL ` | 宏 | 空指针常量；指针未指向任何对象时的合法值 |
| ` gcc ` | 工具 | GNU C 编译器：gcc hello.c -o hello 生成可执行文件 |
| ` make ` | 工具 | 按 Makefile 增量构建 |
| ` %.2f ` | 格式说明 | printf 中输出保留 2 位小数的浮点数 |
