## 嵌入式 Python 工具链与 MicroPython

 

这一册不把 Python 当"另一种单片机语言"，而是讲清它在嵌入式里的 **两个真实位置** ： ① 上位机侧——串口工具、数据分析、构建与 CI、调试台、数据集；② 设备侧——MicroPython 在 ESP32/STM32 上的取舍。 每个脚本都在本机真实运行，数字与输出均可复跑。

本册的定位

 

面向 **已经读完第①册、会在 C 里直接操作寄存器** 的开发者。Python 在这里主要是 **生产力工具** ： 把"手动点串口助手、肉眼找 bug、手工整理数据"变成"一条命令跑完"。

 

设备侧则用  **MicroPython** （ESP32 / STM32）做快速原型：什么时候它够用、什么时候必须回到 C——本册给出明确边界。 与 C/C\+\+/Rust 分册互为参照： **同一件事，谁更适合放在哪一层** 。
