把“能编译但加载失败 / probe 不进来 / 并发崩溃 / 读不到数据”的点集中在一张表里。



| 主题 | 正确做法 | 常见错误 | 后果 |
| --- | --- | --- | --- |
| 模块卸载 | 引用计数归零才卸载 | ref\>0 强行 rmmod | 内核崩溃 |
| 用户态拷贝 | copy\_to/from\_user | 直接解引用用户指针 | 页错误/越权写 |
| 锁选择 | 能睡眠用 mutex，否则 spinlock | 中断里用 mutex | 非法睡眠 |
| 锁顺序 | 全局统一顺序 | 交叉持锁 | 死锁 |
| 中断 | 上半部极短 \+ 下半部 | 上半部做重活 | 中断延迟暴涨 |
| probe 依赖 | 返回 -EPROBE\_DEFER | 直接 -EINVAL | 设备永不 probe |
| 总线 | regmap \+ 超时 | 地址/模式错 | 读回全 0/全 1 |
| [DMA](term:dma) | 按方向 clean/invalidate | 忘维护 cache | 偶发错数据 |
| 电源管理 | get/put 配对 | 漏 put | 永不休眠/耗电 |
| 跨版本 | 适配层 \+ 回归测试 | API 散落各处 | 升级即坏 |
