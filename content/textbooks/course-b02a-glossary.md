## 术语

 

| 术语 | 含义 |
| --- | --- |
| **引用** | 变量/对象的别名（Type&）：不是拷贝，也不能重新绑定；比指针更安全、语法更干净。 |
| **命名空间** | namespace：给名字分组，避免全局名字冲突；用 :: 访问，如 std::cout。 |
| **函数重载** | 同名函数按参数类型/个数区分（编译期决定调用哪个）。 |
| **类** | class：把数据（成员变量）与操作（成员函数）打包成自定义类型的蓝图。 |
| **对象** | 类的一个实例，占据内存、有自己的成员值。 |
| **构造函数** | 对象创建时自动调用，用于初始化；名字与类同名、无返回类型。 |
| **析构函数** | 对象销毁时自动调用（~类名），用于释放资源——RAII 的关键。 |
| **封装** | 用 private/protected/public 控制成员可见性，只暴露必要接口。 |
| **运算符重载** | 为自定义类型定义 \+ - == 等运算符的行为。 |
| **继承** | 派生类复用基类的成员（class B : public A）。 |
| **多态** | 通过基类指针/引用调用时，实际执行派生类的覆写版本；靠虚函数实现。 |
| **虚函数** | virtual 成员函数：运行期按对象真实类型分派（动态绑定）。 |
| **抽象类** | 含纯虚函数（= 0）的类，不能实例化，只作接口使用。 |
| **模板** | template：把类型当参数，一套代码适配多种类型（编译期生成具体版本）。 |
| **STL** | 标准模板库：容器（vector/map…）、迭代器、算法（sort/find…）的统称。 |
| **智能指针** | 自动管理生命周期的“指针”包装：unique\_ptr 独占、shared\_ptr 共享。 |
| **RAII** | 构造获取资源、析构释放；把资源生命周期绑到对象上。 |
| **异常** | try/catch 的错误处理机制：throw 抛出、catch 捕获；嵌入式常关掉。 |

## 符号 / 构件

 

| 符号 / 构件 | 类别 | 说明 |
| --- | --- | --- |
| ` iostream ` | 标准库头 | C\+\+ 的输入输出流头文件（std::cout/std::cin） |
| ` std::cout ` | 标准库对象 | 标准输出流；cout \<\< x 输出，替代 printf |
| ` std::string ` | 标准库类型 | 可增长、带长度管理的字符串类型 |
| ` std::vector ` | 标准库容器 | 动态数组；push\_back/ size/ \[\] 访问 |
| ` class ` | 关键字 | 定义类（默认 private 成员） |
| ` public ` | 访问控制 | 成员对外可见（任何地方可访问） |
| ` private ` | 访问控制 | 仅类内可见的成员 |
| ` virtual ` | 关键字 | 声明虚函数，启用运行期多态 |
| ` template ` | 关键字 | 声明模板，用类型参数 T 生成具体代码 |
| ` std::unique_ptr ` | 智能指针 | 独占[所有权](term:ownership)的智能指针；离开作用域自动释放 |
| ` try / catch ` | 异常 | 异常处理块：try{...}catch(...){} |
