> ◈ 7 步构建路径 · ⚑ 每步可验收

 

把 8 章串成一条路径： **环境声明 → 命令行/脚本 → Git 版本 → 构建依赖 → Python 打包 → 证据阅读 → 干净机器一键复现。**

 

 
1. **① 环境** （M01）——固定 PATH/版本；验收：文档\+脚本可查。
 
2. **② 命令行** （M02）——管道/退出码/查找；验收：批量操作可脚本化。
 
3. **③ 脚本** （M03）——严格模式\+[幂等](term:idempotency)；验收：失败即停。
 
4. **④ 版本** （M04）——小步提交\+标签；验收：源码↔产物可追溯。
 
5. **⑤ 构建** （M05）——依赖锁\+工具链记录；验收：可复现。
 
6. **⑥ Python** （M06）——venv\+锁\+入口；验收：工具随处可跑。
 
7. **⑦ 证据** （M07）——手册/源码\+版本；验收：结论可复核。
 
8. **⑧ 复现** （M08）——干净机器一键；验收：产物与标签一致。
 

 

本册所有“干净机器复现/真实 CI”为工程机实测项；PATH 解析、Shell 退出码、内容寻址、构建拓扑、依赖版本解析等主机可验证部分已给出真实运行结果。
